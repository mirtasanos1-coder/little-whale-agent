小鲸鱼 Agent —— 程序包（V1.6.2）

【怎么用】
1. 双击桌面上的「小鲸鱼」图标（或安装目录里的 小鲸鱼.exe）打开控制台。
   第一次启动会按顺序问三件事：① 免责协议（不同意就退出）→ ② 选运行模式（正常 / 性能模式，低配电脑选性能模式）→ ③ 环境初始化向导。
   向导里语音引擎已内置不用装；QQ 接入端（NapCat）的离线包也随程序带好了，点一下「一键安装（内置离线包）」即可，不需要联网。
2. QQ 登录（V1.3.1 起会自动帮你盯着）：
   软件启动时如果发现 NapCat 没在跑，会自动把它拉起来，并在「设置 → QQ 接入」里显示登录状态：
   · 徽章「没在跑」   → 点「检测并连接」，它会自动拉起，把二维码递到你眼前；
   · 徽章「未登录」   → 点「扫码登录」打开二维码，用手机 QQ 扫一下；
   · 徽章「已登录（QQ xxx）」→ 好了，Agent 会自己连上，不用再管。
   停在设置页时会每 5 秒自动刷新，扫完码会自己变成「已登录」。
   注意：NapCat 是**扫完码才开 3000/3001 端口**的，所以「没登录」时测 WS 连不上是正常的。
   （控制台里点「开始」才开始接消息；不想每次都手动点：设置 → 通用 → 打开「启动后自动工作」）
   V1.4.1 起：改了配置（温度、字数、关心计划、好感度开关等）不用重启，下一句话就按新设置走。
   为了安全，破坏性操作（卸载、更新、重建记忆）现在需要一次性票据；后端只接受本机界面/网页版发来的请求，
　　（V1.6.2 起：打包版不再提供网页版 —— 界面在安装包的前端资源里，网页版只对源码运行有效；请用窗口版。）
   云端 Key 落盘前会加密，管理员「暗号」输错 5 次会锁 10 分钟。
   音视频通话（可选）：包里已带 av_server.exe（自带 Python 运行时），启动时自动拉起，**不需要再装 Python**；
   装不装 Python 都不影响这个功能，缺虚拟声卡时才需要额外装 VB-Cable（界面里会提示）。

3. 「模型设置」分三块：
   ① 本地部署模型（右上开关）—— 点「拉取」选本机模型，再「加入优先级列表」；
   ② API 模型（云端，右上开关）—— 选提供方、填 Key、「拉取」选模型、「保存并切换」、再「加入优先级列表」；
   ③ 模型优先级列表 —— 拖动排序，第一个连不上会自动顺延下一个，最多 10 个。
   两个开关可以同时开，顺序就是实际使用顺序。
4. 「人设编辑」里改完点「保存并重启」立即生效。
5. 「记忆查看」分三块：临时记忆 / 永久记忆 / 日记；临时和永久之间可以勾选后互转。
6. 「活人感」里能看到主动关心计划、主动回复、说说状态、说说评论、浏览动态、表情包、好感度看板。
7. 「设置」里换主题/背景/语言/图标、开自启动、绑定账号、群聊白黑名单、
   记忆策略、NapCat、生图、在线更新、主动回复判定、好感度、卡片透明度、卸载。

【运行前提】
- 本地模型：LM Studio 已启动，并在 127.0.0.1:1234 加载好模型。
  （也可以直接在「模型设置 → 本地部署模型」里点「启动 LM Studio 服务」）
  或者：打开云端 API 开关并填好 Key（那一项就不用开 LM Studio 了）。
- NapCat 已登录 QQ，HTTP 端口 3000、WS 端口 3001 已开启。
  「设置 → QQ 接入」里有「QQ 登录状态」一行：没跑就点「检测并连接」（会自动拉起并给二维码），
  没登录就点「扫码登录」。同一时间**只应该有一个** NapCat 实例在跑 ——
  V1.3.1 起程序不会再重复启动；如果看到「检测到 N 个进程」的提示，点一次「检测并连接」会自动清场。
- 首次运行若 Windows 提示缺 WebView2，请安装：
  https://developer.microsoft.com/microsoft-edge/webview2/

【目录说明】
- 小鲸鱼.exe          主程序（GUI）
- config.json         全部可调参数（模型链、地址、token 预算、主题、开关…），界面会写它
- personas.json       人设，纯 JSON，随便加、随便改，界面也能改
- memory/             记忆目录（v7 起）：memory.db + exports/ + backups/
- stickers/           表情包目录，往里丢 png/jpg/gif 就能用，文件名带情绪词自动分类
- themes/             自定义主题目录，放 .json 就能在「设置 → 外观」里选到
- icons/              自定义图标目录，放 png/jpg/svg 就能替换左上角的「鲸」
- backgrounds/        自定义背景目录，放图片就能在「设置 → 背景与语言」里选到
- langs/              语言包目录，复制 zh-CN.json 改成 ja-JP.json 翻一遍就是新语言
- moment_images/      发说说时用的预置图片（可选）
- generated/          生图输出目录（开了生图才会有）
- qzone_inbox/        说说评论收件箱（NapCat 版本读不到评论时，手动把评论丢这里）
- feed_inbox/         动态收件箱（v7：读不到说说列表时，手动把看到的动态丢这里）
- memory_backup/      记忆导出与重编译前的备份（自动生成）
- memory.db           老版本数据库（如果还在根目录，启动时会复制进 memory/，老文件保留）
- agent.log           运行时日志，出问题先看这个
- Docs\               所有文档都在这里（技术文档、更新日志、开发进程、人设指南…）
- Docs\TECH_DOC.md    完整技术文档（架构、数据库、400 排查、二次开发、打包）
- Docs\更新日志.md     v1 → V1.2.1 每一版改了什么（唯一集中的更新日志）
- Docs\开发进程文档.md  版本演进、进程模型、踩过的坑、交接清单
- Docs\人设自定义指南.md  人设怎么写才有效
- Docs\数据库字段变更清单.md  数据库加了哪些表/列
- Docs\V1.2.1-更新说明.md 等  各版本的「人话版」说明（留档）
- desktop\            桌面端源码（Tauri 外壳 + 前端 index.html）
- legacy\             旧的 pywebview 版程序（V1.1.6 及更早，已停用，留档不删）
- tests\              自检/调试脚本（开发用，不影响使用）
- 使用说明.txt        本文件（中文）
- 使用说明_EN.txt     English quick start（同一份内容的英文版）
- 启动.bat            双击启动桌面端（找不到桌面端时退化成「后端 + 浏览器」）
- 启动网页版.bat      调试用：只起后端，浏览器打开 http://127.0.0.1:5701/
- 打包后端.bat        源码包用：把后端打成 backend_server.exe
- 打包桌面端.bat      源码包用：打出安装包与绿色版
- requirements.txt    只在「源码包」里有：跑起来需要的依赖（pip install -r requirements.txt）

【V1.1.2 新增（正式版）】
- 回复不再慢半拍：聊天超时独立 60 秒，超时只换短上下文再试一次；打字延迟封顶 2 秒；
- 问了会回：只认真发出去才算回过，问句永不拦（以前会被静默吞 90 秒）；
- 后台提取排队：记忆/事件/永久记忆提取等你安静 8 秒才跑，不再抢模型；
- 群聊接得上：@ 我与补回消息都带最近对话，整批回一条，不再只会「在的」；
- 记忆页能自己挑会话：私聊/群聊下拉 + 「已绑定」标记 + 最近一条内容；
- 待办可选「模型自己判断 / 只手动加」，还能写额外提示词；
- 界面不抖：右上角全部定宽；开关换成滑动胶囊；「关于」挪到最后一栏；
- 启动过场：转圈 + 「请稍等噢，马上就好~」，首屏画好自动淡出；
- 日记备份间隔只能填数字（≤9999），切单位自动换算总时长；
- 画图页写明必须接云端绘图 API，本地聊天模型只出文字。

【V1.1.1 新增（正式版）】
- 更像人：下午说「早上好」会被接住；引用收紧（隔两条才引用）；群里叫名字就回，不用 @；
  90 秒内同一句不重复回；默认 1~3 句，不写小作文；7~23 点刚上线会主动打招呼。
- 人设字段化：姓名/昵称/性别/年龄/身份/性格/风格/口头禅/雷区/背景/示例分格填。
- 学习：新标签「学习」，自动学 / 按条件学 / 动手学；条件文本框常显，条目可编辑、可多选并行应用。
- 画图：新标签「画图」，最高 720P，模型可自己决定配不配图，学会了记一条学习经验。
- 管理员控制台：新标签「管理员」，暗号解锁、界面模糊遮罩、最高权限提示词（跳过防护）、一页纸诊断。
- 启动顺序检测：QQ → 模型 → 出话 → 出图 → 读图 → 动态，六步依次测；测试垃圾一键清。
- 一键启动：NapCat → 本地模型服务（会自动找 ollama.exe）→ Agent。
- 好感度看板 + 情感感知：看得出来你在丧、在开心，也看得见谁最熟。
- 日记独立备份（diary_backup/）；记忆支持「丢进 memory_import/ 自动导入」；单位切换自动换算。
- 深色标题栏（白框没了）、关窗口进托盘、鲸鱼图标；安全核心只发 .pyc，不进开源包。

【V1.1.0 新增（正式版）】
- 模型设置重做：「本地部署」卡只管启用/停用（可选 LM Studio / Ollama），「API」卡只放云端，
  两张卡开关关掉会整块置灰；「保存并应用」= 直接放进优先级列表第 1 位生效，
  不再需要另外点「加入优先级」「应用模型」；优先级列表每行可以「编辑」、可以拖动排序，
  第 1 行标「首选」，底部一句话说清失败顺延规则。
- 人设改版：一个人设一张卡片一个文件，字段按「姓名/性格/年龄/身份…」分开展示，
  支持新建、复制、导入导出、单独切换，切换不牵连其他卡片。
- 记忆备份：手动导出（JSON/TXT/整目录）+ 定时自动导出（默认关闭，可设秒/分/时/天/周/月/年，
  最长 365 天，输入框只收数字）+ 把备份丢进 memory_import/ 就会自动导入。
- 用量明细：「这一笔做了什么」不再空白，会写清「用途 · 场景 · 对象」；用量可导出/导入 CSV。
- 安全：SQL/提示词/命令注入防护默认开启；管理员暗号默认关闭且不在界面显示，开启时要读满
  10 秒风险提示才能确认；API Key 加密保存且保存后不再显示明文；启动可校验文件完整性。
- 界面：新增动效引擎（总开关 / 速率 / 光效亮度 / 悬停 / 切页 / 水波纹，可预览）；
  修好「公告与通知」里绿色提示被卡片遮住的问题。
- 版本：左上角统一显示「正式版 · v1.1.0」，程序目录挪到「设置 → 关于」，
  关于里能看到版本号、版本类型、作者（Ruao）和免责声明。
- 首次启动要同意免责协议（只弹一次，同意后不再弹）。
- 公告：v4~v8 的历史公告合并成一条 V1.1.0 公告，不再一次弹 5 个窗。
- 更新：支持 GitHub + 网盘镜像两种通道（默认不自动下载安装，默认要求签名校验），
  更新流程不会上传任何本地数据与人设、Key。

【v8 新增】
- 主动回复重做：以前到点还要「对方安静 2 小时」才发，所以刚聊过天时设的测试条目不响。
  现在「设置 → 主动回复」可以自己定：安静几小时（支持小数，填 0 = 到点就发）、
  判定方式（只看时长 / 让模型自己挑时候）、多久检查一次。
- 好感度系统（默认关）：每人一个分数，7 档关系，会影响回话语气但不会报分数；
  「活人感」页有看板，能清零、能手动设分。
- 卡片透明度：设置 → 外观有滑块（20%~100%），松手预览，保存后重启不丢。
- 英文界面修好了：以前切 English 一点变化都没有（后端不认语言参数 + 数据目录里那份语言文件是空样板）。
- 公告改成堆叠卡片：最多 4 张错开叠放，只有最上面能点，已读的不再显示。
- 说说条数自己定：每天最少/最多几条（0~50），超过 30 会提醒「设置太多会出问题的~」。
- 日记升级：到点自动写，会综合人设 + 今天新记住的 + 以前记住的 + 今天的聊天；
  没绑定账号也能手动生成。
- 生图直接用当前模型链路：当前模型不支持就自动换列表里下一个。
- 关心计划识别更准（会带上前几条对话），关掉后那一整块不再显示。
- 一键卸载：设置 → 卸载本软件，先看清单（删什么/留什么），可保留记忆与配置。

【v7 新增】
- 模型设置重做：本地部署模型 / API 模型（云端）各一个开关，可以同时开；
  「拉取」后是真正的下拉框（上一版那个小箭头点了不弹，是 WebView2 的 datalist 老毛病）。
- 模型优先级列表：拖动排序、↑↓、删除、清空，最多 10 个；
  第一个连不上自动顺延到下一个（「第一个失败就顺延」可关）。
- 浏览动态：模型能去看别人的说说，自己决定点赞还是评论，也可以设成"全都赞+评"或"只看"；
  你在评论区回它，它会一直回到没人再回为止。
  注意：多数 NapCat 读不到说说列表，此时把动态贴进 feed_inbox/ 点「现在看一轮」。
- 主动关心计划 / 主动回复：各有一块列表，能筛选、就地改时间与问法、取消、删除、手动新增。
- 临时记忆 ⇄ 永久记忆：勾选后一键互转（永久转临时只是标记，不删数据，可恢复）。
- 记忆统一放在 memory/ 目录，界面「记忆 → 打开记忆目录」一键跳过去。
- 背景换图立刻生效（以前选完还要点「应用」）。

【v6 新增】
- 背景自定义：图片丢进 backgrounds/，「设置 → 背景与语言」里选，可调压缩程度/模糊/填充方式。
- 多语言：内置中文/英文，复制 langs/zh-CN.json 改成别的语言码翻一遍即可，界面会掉出新的选项。
- 主动关心计划（场景感知）：你随口说「我一会儿下课」「明天考完」，模型会在后台排一条
  到点来问你的计划（列表在「活人感」，可手动加/改/删；也可设成只手动或只模型）。
- 说说增强：发不发可由模型自己判断（也可改回"到点就发"）、可配图（预置图/表情包/生图）、

  从别的软件搬家过来，导出 CSV/Markdown 再导入也能认。
- 打开目录的按钮全部修好了（以前点了没反应，其实是窗口开在了后面）。

【v5 新增】

  不再两条互相矛盾。旧条目不删，能在界面上看到，也能追溯。
- 记忆三档策略（设置 → 记忆策略）：
    模型自己判断（默认，省 token） / 每条都记（会有点噪音） / 只存临时缓存（不留永久记忆）

  / 硅基流动 / 自定义），带 token 统计和日限额，超了自动停，防止账单失控。
  API Key 只写本机 config.json，不进开源包。
- QQ 接入（NapCat）集成：自动检测状态、一键启动、检查最新版本、下载安装。

【v4 新增：设置中心】
- 主题：内置 5 套（深海蓝/日光白/浅海青/樱粉/苔绿），也支持 themes/ 里放 json 自定义
- 自定义图标：icons/ 里放图片，「设置 → 外观」里选
- 开机自启动：写 HKCU 注册表，不需要管理员权限，可随时关掉
- 日记：绑定 QQ 号后每天自动写一篇第一人称日记，并提炼永久记忆

- 群聊绑定：可选「全部回复 / 只回白名单 / 屏蔽黑名单」，各最多 20 个群
- 保存群聊记忆：默认关（只有 @ 时才记），开了所有群消息都进上下文
- 在线更新：填 GitHub 仓库名（如 yourname/qq-agent），一键检查/更新/回滚
- 公告栏：开发者功能，内容写在 notice.py 里，界面上没有按钮

【活人感功能】
- 私聊每条消息都会用「引用回复」，像真人回你
- 离线期间收到的私聊，启动后自动补回（不限时间）
- 每天随机 1~10 条 QQ 空间说说，内容由模型根据当天聊天自己判断
- 回复里会自然带 emoji；情绪对得上时补一张表情包
- 12:00 / 18:30 没人说话会主动问一句
- 你说过的考试/出差/复查等事，到点会主动来问
- 你说的「一会儿下课」这类短时安排，会排成「关心计划」到点来问
- 群里 @ 你之前别人说的话，也会被一起读进去

这些在界面「活人感」标签页里都能看到状态、手动测试。
想关掉某项就改 config.json 里对应的开关（如 moment_enabled / sticker_enabled / care_plan_enabled）。

【表情包怎么加】
把图片丢进 stickers/ 目录，文件名带上情绪词即可，例如：
  开心_好耶.png、生气_炸毛.png、无语_汗.png
支持的情绪：开心 生气 委屈 无语 害羞 调皮 惊讶 困 爱心 点赞 吃饭 打招呼
改完在界面「活人感」→「重新扫描」就能看到。

【主题怎么自定义】
在 themes/ 里新建一个 json，例如 我的主题.json：
{
  "name": "我的主题",
  "vars": {
    "bg": "#101418", "panel": "#171d23", "text": "#e6edf3",
    "muted": "#8b949e", "accent": "#58a6ff", "line": "#30363d"
  }
}
然后在「设置 → 外观 → 主题」里刷新就能选到。颜色只接受 #hex / rgb() / hsl()。

【加一门语言】
1. 打开 langs/ 目录，复制 zh-CN.json，改名成 ja-JP.json（语言码参照 BCP47）。
2. 用记事本打开，把右边引号里的中文翻成你要的语言，左边的 key 一个字都别动。
3. 回界面「设置 → 背景与语言 → 界面语言」点「刷新」就能选到。
没翻译到的 key 会自动退回中文，不会报错。

【改了电脑 / 换了模型怎么办】
打开界面「模型设置」：
- 本地：点「本地部署模型」卡里的「拉取」→ 下拉选一个模型 →「保存本地模型」→「加入优先级列表」。
- 云端：「API 模型（云端）」→ 选提供方 → 填 Key →「拉取」→ 下拉选模型 →「保存并切换」→「加入优先级列表」。
最省事的做法是**两个都加进优先级列表**：本地挂了自动用云端，云端欠费自动回本地。
如果模型是推理模型（Qwen3 / DeepSeek-R1 这类会先"想"再说的），
界面「测试第一个能不能出话」会告诉你它是不是把 token 全花在思考上了，
这时把 reasoning_max_tokens 调大（默认 4000 一般够）。

【常见问题】
- 界面白屏：缺 WebView2 运行时，按上面链接安装。
- 回复为空 / 400：看 agent.log 里的 [模型] 行，会打印服务端的原始报错原文。
  最常见三种：①模型名写错（去「模型设置」点「拉取」重选）
  ②推理模型 token 不够 ③LM Studio 的本地服务器没启动（点「启动 LM Studio 服务」）
- 拉取模型后点下拉箭头什么都不出来：v7 已修（改成原生下拉）。
  先点「拉取」，等结果行变绿再点下拉。
- 第一个模型连不上就不说话了：看 agent.log 搜「顺延下一个」。
  如果只看到第一个失败就结束，检查「第一个失败就顺延」开关是不是关了。
- 两个开关都开了但只用了一个：优先级列表里可能没有另一种类型的项，
  回对应卡片点「加入优先级列表」。
- 切了云端还提示"LM Studio 未启用"：v6 已修；若还出现，去「模型设置」
  确认「API 模型（云端）」卡里的地址和 Key 是对的，点「保存并切换」再试。
- 收到消息但不回复：agent.log 里搜 [人设] 和 [模型]，看系统提示词有没有加载成功。
- 永久记忆一直是空的：先在「设置 → 日记与永久记忆」里绑定 QQ 号，没绑定不写。
- 记忆文件在哪：界面「记忆 → 打开记忆目录」，统一在 memory/ 里（含 exports/ 和 backups/）。
- 群聊不回复：检查「设置 → 群聊绑定」的模式，白名单模式下只回名单里的群。
- 开机没自启：检查「设置 → 启动与系统」的自启动开关，或看注册表
  HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run 里有没有「小鲸鱼Agent」。
- 点了"打开目录"没反应：v6 已修（窗口会被主动提到最前）。若仍看不到，
  看任务栏的资源管理器窗口，Windows 11 有时会把新目录开在已有窗口里。
- 发说说失败：agent.log 里搜 [说说]；QQ 空间接口偶尔抽风（ENOTFOUND）会自己恢复。
- 浏览动态一条都看不到：多数 NapCat 读不到说说列表（返回"不支持的Api"），
  把看到的动态贴进 feed_inbox/*.txt，点「现在看一轮」。
- 说话的口气不对：改 personas.json，不用重启程序，界面「保存并重启」即可。
