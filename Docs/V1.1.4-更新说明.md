# V1.1.4 更新说明（用户向）

> 这次是「底层规矩」版。界面上变化不多，但你之前的抱怨基本都对着改了一遍：
> 群里 @ 终于带前文了、模型会先想再说、数据库以后只增不删、伴侣关系和好感度分开了。

## 一、升级后先做三件事

1. **不用管数据**：新版只加表/加列，老记忆、好感度、聊天记录全部原样保留。想稳妥就先在「设置 → 配置」点一次备份。
2. **看看群聊有没有变好**：在群里连着 @ 它两次，第二次它会知道前面在聊什么（以前第二条完全不知道）。
3. **语音是可选功能**：想让它发语音，设置里打开「语音」，机器上需要 `pip install edge-tts`；没装也不影响文字聊天。

## 二、群聊上下文（这次的重点）

| 以前 | 现在 |
|---|---|
| 只 @ 不说话才拼上下文 | 只要 @ 就拼「@ 前 N 条 + @ 后 M 条」 |
| 遇到别人的 @ 就截断 | 只按「时间断层」和「连续灌水」截断 |
| 第二条 @ 完全没前文 | 每条 @ 都带前文 |

## 三、先想再说

模型回话前会先在内部写 1~3 句判断（这句话什么情绪、该不该接、接哪点），再写正文。
你在界面上看不到那些思考，但它会进日志；正文里不会漏出 `<thinking>` 标签。

## 四、数据库这次的改动（只增不删）

- 新表 3 张：情绪日志、伴侣关系、思考存档。
- 老表加列 5 个：事件单位、关心计划单位、用量功能位、好感度伴侣标记、思考消息数。
- 一个换算：老的「静默 2 小时」→ 新的「7200 秒」，迁移只跑一次，不会变成 2 秒。
- 详细清单见源码包里的《数据库字段变更清单.md》。

## 五、伴侣模块

- 关系：朋友 / 挚友 / 心动 / 恋人 / 伴侣，在「好感度」页底部设置。
- 和分数分开存：把好感度清零，关系不会跟着丢。
- 群聊里永远踩刹车：不管设成什么关系，群里一律不撒娇不占有。

## 六、唤醒守护

群里有人喊「醒醒 / 在吗 / 在不在」，即使没 @ 也会被叫醒回一句；同一时间段只叫一次，防止被刷屏。

## 七、学习红线

认知 / 价值观这类会进角色底色的学习内容，一旦碰到极端、违法、涉黄涉暴，直接不收，并写一条 WARN 日志。

## 八、这次还没做

- 回复优先级队列（按情绪权重决定先回谁）——设计已写进变更清单，代码没动。
- 记忆分层（事实 / 情绪 / 剧情分槽存放）——同上。
- 网页版仍然只转发事件，不渲染界面。

## 九、出问题怎么办

1. 先看控制台最后 30 行，红色 WARN/ERROR 会写清哪个模块。
2. 设置里点「备份记忆」，再试「系统自检」。
3. 语音不响：先确认 `edge-tts` 装了、`tts_max_chars` 没把长句挡掉。

### 又补的：两个开关终于听话了

- 主动回复的「静默多久才说话」以前填 0 或 0.5 会被吞掉，现在填多少就是多少；设置里刚打开也会立刻生效，不用重启。
- 新增「被叫到后进入守护态」：@ 它一下之后 10 秒内，群里正常聊天它也接（默认开，3~120 秒可调）。
- 学习页多了一个「学习安全底线」开关：默认开着；要关必须读完免责协议、勾选同意、等满 10 秒、签名；签完会在本机存一份协议，删掉协议文件就自动重新开启。

## 又补的几处（同一版，不用再升级）

- **不会开出第二个控制台了**：再点一次图标，是把已经开着的窗口叫到前面。
- **重启现在真的会起来**：以前「重启」等于把自己和刚拉起来的新窗口一起关掉。
- **积雪照着你给的图重做了**：厚厚一层压在卡片上、底边是波浪的、边缘发虚；
  换主题时会先塌下来化掉，不是啪一下消失。
- **免责协议点不动的时候会告诉你为什么**：按钮变灰，点一下会提示「请先勾选/还要再等几秒」。
- **人设可以传「形象图」了**：人设 → 形象图，传一张或多张；点「识别长相」让模型记住她长什么样。
  之后你说「发张你的自拍」，它会按这张脸画，不会突然换成另一个人。

### 这一版又顺手补的

- **好感度等级说明对上了**：之前页面上写的档位和程序里实际的完全不是一套，现在按真实档位重写（陌生人 / 认识的人 / 熟人 / 朋友 / 好朋友 / 知己 / 特别的人）。
- **好感度开关改完立刻生效**：不用重启，也不会再出现「开了又显示关」。
- **安全核心换了存放形式**：你存的 Key 照样能解，不用重填。
- **加了并发自测**：7 个用例专查多线程下的记忆、配置、学习、密钥，跑一次 1 秒。
