## 一、升级后建议先做的三件事

1. **去「活人感」看一眼主动关心计划** —— 这个功能默认开启，但需要你的模型在对话里判断出「该关心」才会排。先试一句「我一会儿要下课了」，然后去「设置 → 主动关心计划」看有没有出现一条待发的。
2. **去「设置 → 背景与语言」挑个背景** —— 放一张图进 `backgrounds/` 目录，点「刷新」，选中，点「应用」。
3. **确认一下模型来源还是你想要的** —— 上一版修了云端切换的 bug，如果你之前填过云端 Key，去「模型设置 → 模型来源」确认一下现在是「本地」还是「云端」。

## 二、背景自定义

把图片放进程序目录的 `backgrounds/` 文件夹，界面「设置 → 背景与语言」下拉里就会出现。

| 参数 | 作用 | 建议 |
|---|---|---|
| 压暗程度 | 0~90，越大背景越暗、文字越清楚 | 亮图用 45~60，暗图用 25~35 |
| 模糊 | 0~40，越大越朦胧 | 细节太多的照片用 8~15 |
| 填充方式 | 铺满裁切 / 完整显示 / 平铺 | 大多数情况用「铺满」 |

> 背景和主题是两层：背景是底图，主题是配色。两个可以随便组合。

## 三、多语言

内置简体中文和 English。想加第三门语言，**不用改代码**：

1. 打开 `langs/` 文件夹，复制 `zh-CN.json`，改名成 `ja-JP.json`（语言码随意，参考 `en-US` 这种格式）；
2. 用记事本打开，**只改冒号右边引号里的字**，左边的 key 一个字都不能动；
3. 回界面「设置 → 背景与语言」，点「刷新」，下拉里就多一项。

翻漏了不会报错 —— 缺的会自动显示中文。

> 注意：这只改界面上的按钮和提示。**模型说的话由人设决定**（`personas.json`），不跟着语言走。

## 四、主动关心计划（场景感知）

这是这一版最核心的新功能。和以前那个「智能查岗」不是一回事：

| | 以前的查岗 | 现在的主动关心 |
|---|---|---|
| 什么时候 | 事情**已经过去**了才问（考完了问考得怎么样） | 事情**快发生**时问（快下课了吧） |
| 谁说 | 系统按时间触发 | **模型自己判断**该不该关心 |
| 例子 | 「考得怎么样？」 | 「快下课了吧？今天上了什么课」 |

**怎么工作**

你说「我一会儿要下课了，好累」→ 模型在记事件的时候顺手判断「这个该到点关心一下」→ 后台排一条计划（比如 15:40）→ 到点了自动发一句。

**不会变成骚扰**，有五道闸门：

1. 只在 8:00~23:00 发；
2. 每天最多 6 条；
3. 两次之间至少隔 25 分钟；
4. 你 8 分钟内刚说过话就跳过（人家正聊着，不用关心）；
5. 模型不可用时宁可不发。

**谁能决定排计划**（设置里可选）：

- `模型自己决定`（默认，推荐）：只有模型觉得该关心才排；
- `只能我手动加`：模型不排，你在界面「活人感 → 主动关心计划 → 加一条」自己加；
- `两者都行`。

手动加一条支持三种时间写法：`+30m`（30 分钟后）、`2026-10-22 15:40`、`15:40`（已经过了就自动算明天）。

## 五、说说增强

### 5.1 让模型决定发不发

以前的说说像闹钟：到点就发。现在默认是「到点了问模型一声：现在适合发吗？」

- 模型觉得没什么好说的就回 `SKIP`，这条就不发 —— 所以**一天可能一条都没有**，这很正常，真人也不会每天硬凑。
- 如果你就想要固定节奏，设置里把「发不发由谁决定」改成 `到点就发`。

### 5.2 说说配图

可以给说说配图了，四种来源：

| 来源 | 图从哪来 |
|---|---|
| 预制图 | 你自己放进 `moment_images/` 的图 |
| 表情包 | 从表情包库随机抽 |
| 现生成 | 调生图模型现画（需要开生图） |
| 混着来（默认） | 上面三种哪个有就用哪个 |

每条最多几张图也能配（0~9）。

## 六、回复说说评论（可开关）

有人评论你的说说，模型会看「那条说说写了什么」+「评论说了什么」，生成一句像样的回复。

投递方式：优先回在评论区；评论区接口不支持时，私聊发给评论人。

> **一个必须知道的现实限制**：大多数 NapCat 版本**读不到说说评论**（接口不存在）。
> 为此做了一个 `qzone_inbox/` 目录当"收件箱" —— 你在手机上看到评论，复制粘贴进这个目录（一行一条，或 `昵称: 内容`），程序会当成评论处理并回复。
> 界面「活人感 → 说说评论」有「收件箱」「收取」两个按钮。

同一条评论有去重，不会回好几遍。

## 七、生图（可选）

接 OpenAI 兼容的 `/images/generations` 接口。两个用途：

1. **说说配图**：让说说配上「现画的图」；
2. **聊天表情包**：让聊天里发自己生成的图。

**怎么开**：设置 → 生图 → 填好接口地址（要以 `/v1` 结尾）、模型名、API Key → 打开开关。

聊天里发生成图需要两个开关同时打开，而且默认只有 12% 的概率会生图 —— 大部分时候还是发预置的表情包（生图慢、费钱，没必要每句都生）。

**生图不会卡住聊天**：文字先发出去，图在后头慢慢生成，好了再补一条。

## 八、用量明细

用量看板现在能看「每一笔花在哪了」：

- 聊天回复、记忆提炼、发说说、写日记、离线补回、滚动摘要、生图、主动关心、评论回复、事件提取……

支持按用途筛选、按天看。这样月末看账单时，能知道是"聊天聊多了"还是"日记写多了"。

## 九、记忆多格式导入导出

**为什么做这个**：你之前提到可能有别的类似软件的记忆要迁过来。

**导出** 6 种格式：

| 格式 | 适合 |
|---|---|
| `qq-agent`（原生 JSON） | 备份、迁回本程序 |
| 通用 JSON | 给别的程序吃 |
| JSONL | 一行一条，方便脚本处理 |
| CSV | 用 Excel 打开、手改 |
| Markdown | 直接看、贴进笔记 |
| 纯文本 | 最通用，一行一条 |

**导入** 会自动识别格式，认不出来可以手动指定。合并进库时，冲突的旧条目会被标成"已替换"。

> 临时聊天上下文默认**不导出** —— 那是聊天上下文，不是"记忆"。

## 十、这一版修掉的问题

| 问题 | 原因 | 现在 |
|---|---|---|
| **所有「打开目录」点了没反应** | 资源管理器窗口被拉到本程序后面，Win11 又默认在同一个窗口打开新文件夹 | 12 处全部改成主动抢前台，实测 12/12 成功 |
| **填了云端 Key 却提示「LM Studio 未启用」** | 拉模型列表的函数写死了本地地址，选了云端照样敲 `127.0.0.1:1234` | 按当前提供方自动选地址和字段；401 给中文指引 |
| 云端下保存模型会改到本地配置 | `set_model` 写死写 `lm_model` | 自动判断该写 `cloud_model` 还是 `lm_model` |
| 切了云端「测试连通」还在打本地 | 模型地址是导入时算的，没刷新 | 测试前先刷新模型地址 |
| 用量看板有的用途显示英文 | 新分类没加中文 | 补齐 13 类，后端也直接返回中文 |
| 生图设置保存不下来 | 前端传短键、后端认长键 | 加了别名映射 |
| 说说评论回重复 | — | 按 `(说说ID, 评论人, 内容)` 去重 |

## 十三、如果你从 v5 直接升上来

1. 把新的程序包解压，**覆盖**到原来的目录（你的 `config.json` / `personas.json` / `memory.db` / `stickers/` / `themes/` 都不会被覆盖）；
2. 双击 exe，会弹一条 v6 公告，点「知道了」；
3. 老数据库会自动补两张新表，不用手动迁移；
4. 去「设置」看看新加的几张卡：背景与语言、生图、主动关心计划、说说增强、说说评论。

**完全没动的东西**：人设、永久记忆、日记、表情包、主题、图标、群绑定、在线更新设置 —— 都是原样。
