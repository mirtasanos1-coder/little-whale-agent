# 主题特效开发指南（V1.3.0）

> 从 V1.3.0 起，「背景飘雪 / 落叶」改名 **背景特效**，卡片上沿的雪堆改名 **卡片视觉效果**，
> 两者都做成了**可扩展**的：不用改后端，只改前端（`desktop/src/index.html`）就能加新样式。

---

## 一、背景特效：加一种新的飘落物

背景特效在一个注册表里，叫 `window.FX_KINDS`。每一项描述「飘什么、多大、多快」：

```js
window.FX_KINDS = window.FX_KINDS || {
  snow:   { label: '飘雪', glyphs: ['❄'],            size: [8, 18],  dur: [6, 14] },
  leaf:   { label: '落叶', glyphs: ['🍁', '🍂', '🍃'], size: [13, 25], dur: [7, 16] },
  sakura: { label: '樱花', glyphs: ['🌸', '🌺'],       size: [10, 20], dur: [8, 18] },
  rain:   { label: '细雨', glyphs: ['💧', '💦'],       size: [8, 14],  dur: [2, 4] }
};
```

字段含义：

| 字段 | 含义 |
|---|---|
| `glyphs` | 字符池，每一片随机取一个（emoji 或普通字符都行） |
| `size` | `[最小, 最大]` 字号，px |
| `dur` | `[最快, 最慢]` 一次飘落耗时，秒（越小越快） |

**加「花瓣」的四步**（照抄就能跑）：

1. 找到 `desktop/src/index.html` 里的 `window.FX_KINDS`，加一行：

   ```js
   petal: { label: '花瓣', glyphs: ['🌸', '🌷'], size: [12, 22], dur: [9, 16] }
   ```

2. 设置页「背景特效样式」那个 `<select id="bgFx">` 里补一个选项：

   ```html
   <option value="petal">花瓣</option>
   ```

3. 完事。保存外观 / 选一下这个选项，`applyThemeFx()` 会自动用它。
4. 想让它成为某个主题的默认：在主题的 `effects` 里写 `"bg_effect": "petal"`。

> 注意：`bg_effect` 为空 = **跟随主题**（雪夜主题飘雪、金秋主题落叶）；
> 用户在设置里钉死一种之后，主题再换也不影响他的选择。

## 二、卡片视觉效果：加一种新的上沿装饰

卡片装饰由两层决定：

1. **开不开**：设置里的「卡片视觉效果」开关 → 配置项 `card_snow_enabled`；
2. **长什么样**：设置里的「卡片视觉样式」下拉 → 配置项 `card_effect`（`snow` / `glow` / `none`）。

样式最终落在 `<html>` 的两个 data 属性上，纯 CSS 就能接管：

```html
<html data-card-fx="snow" data-snow-card="1">
```

加一种「彩虹描边」的步骤：

1. 在 `<style>` 里加一条规则（建议挨着 `/* v1.3.0 ⑰：卡片视觉样式 */` 这段写）：

   ```css
   html[data-card-fx="rainbow"] .card,
   html[data-card-fx="rainbow"] .panel {
     box-shadow: 0 0 0 1px rgba(255, 0, 128, .45), 0 14px 34px -18px rgba(56, 189, 248, .5);
     background-image: linear-gradient(120deg, rgba(255, 0, 128, .06), rgba(56, 189, 248, .06));
   }
   ```

2. 设置页「卡片视觉样式」下拉里补 `<option value="rainbow">彩虹描边</option>`。
3. 想默认生效：配置里 `card_effect: "rainbow"`。

> 想让某个样式**同时用上雪堆**：不要在 CSS 里删 `::before`，
> 因为雪堆是 `html[data-snow-card="1"] .card::before` 画的；
> `data-snow-card` 只受「开关」和 `card_effect === 'none'` 影响。

## 三、主题自己带特效

主题文件里的 `effects` 支持这些键（V1.3.0 起）：

| 键 | 说明 |
|---|---|
| `snow` | 飘落物数量（0~120） |
| `leaves` | 老字段，`true` = 落叶，`false` = 飘雪（新代码优先看 `bg_effect`） |
| `bg_effect` | 钉死一种背景特效 id（见上面的注册表） |
| `card_effect` | `snow` / `glow` / `none` |
| `card_snow` | 老字段，等价于「卡片视觉效果开」 |
| `flakes` | 老字段，等价于「背景特效开」 |
| `depth` | 雪堆厚度 0~100（老字段，用户设置里的滑块优先） |
| `edge` | 是否画主题自带的边框光 |

**优先级**：用户设置 > 主题自带 > 代码默认。这样「关了雪又自己开回来」的老问题不会再出现。

## 四、性能模式下的表现

打开「性能模式（低配电脑）」后：

- 所有 CSS 过渡 / 动画进 `none`；
- 毛玻璃（`backdrop-filter`）关掉，改纯色；
- `#snowLayer`、`#fxLayer`、粒子与雪堆全部不画；
- 导航滑块改为瞬间定位（不滑）。

所以新加的特效用 `transition` / `animation` 写就能自动被性能模式接管；
如果用 JS 定时器做动画，请在 `applyEffects()` 里加一句 `if (window.__PERF_LOW) return;`。

## 五、常见坑

1. **别在 `applyThemeFx()` 里直接读 localStorage**：真值以 settings 缓存为准，
   否则换数据目录/换机器后表现不一致。
2. **`FX_KINDS` 的 key 不要用中文**：它会进配置文件和 URL 参数。
3. **新样式别忘了性能模式**：低配用户开性能模式时，你那层装饰应该整个消失。
4. **改完必须重新打包**：`index.html` 是运行时从磁盘读的（绿色版改完即生效），
   但安装版里的前端是**嵌进 exe** 的 —— 改完要 `打包发布.py` 重新出包。
5. **新特效的 key 必须同时登记到 `config.py` 的 `FX_BG_ALLOWED`（或 `FX_CARD_ALLOWED`）**，
   否则前端的「保存」会被后端退回来（提示「`bg_effect` 只能取 (...)」）。
   这两组常量是**白名单**，不是摆设：它挡住乱填的字符串，也顺便给下拉框定了合法值。
6. **粒子的「数量」不是主题给的，就是你选的**：`applyThemeFx(eff)` 里的 `n` 来自**主题**的
   `effects.snow`；用户在设置里手选「樱花/落叶/细雨」时主题多半没给这个数，
   v1.3.0 于是 `cnt=0`、整层直接 `return`（选了等于没选）。
   v1.3.1 起：**手选了样式就按「厚度」滑块换算**（`厚度 × 0.55`，夹 12~60），没手选才跟随主题。
   你加新飘落物时不用再管数量，只要给 `FX_KINDS` 里那条配 `glyphs/size/dur`。
7. **绝对不要把 `bg_effect` / `card_effect` 放进 `_BOOL_KEYS`**（`config.py` 里那批开关的名字列表）。
   v1.3.0 就栽在这上面：用户选「樱花」，写配置时被强转成 `True`，
   界面上再也选不回来、特效也不生效，而且**没有任何报错**。
   判别标准很简单：**这个键有多个取值吗？有就不能当开关。**
   顺带一提，`config.load()` 里现在有一段自愈：读到历史布尔值会自动改回字符串并存盘。
