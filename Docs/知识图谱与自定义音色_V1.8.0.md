# 知识图谱记忆 与 自定义音色（V1.8.0）

> 这一版加了两样东西：**它开始记得住「谁和谁是什么关系」**，以及**它可以用你自己的声音说话**。
> 两样都是可选增强：不用也不影响任何原有功能，坏了也不会让程序打不开。

---

## 一、知识图谱记忆

### 1.1 它解决了什么问题

以前的「永久记忆」是一条条**互不相干的事实**：

```
张三养了一只叫橘子的猫
李四是张三的老板
```

问「**老板那只猫叫什么**」，老版本检索不到 —— 因为这句话里既没有「张三」也没有「橘子」。
V1.8.0 把事实拆成**三元组**（主语—谓词—宾语），连成一张网，这个问题就能沿着网走两跳答出来：

```
李四 —(是…的老板)→ 张三 —(养了)→ 橘子
```

### 1.2 怎么工作（用户视角）

- **抽永久记忆时顺手织网**：聊天里提炼出新的永久记忆时，模型会顺带给出 0~3 组关系。拆不出来就不给，不影响记忆本身。
- **老记忆慢慢补**：后台线程一天补一批（默认 20~50 条），不抢聊天的资源，也不用你管。
- **答话时自动用**：每轮对话都会试着找一遍跟这句话相连的关系，找到就塞进上下文；**找不到就不塞，不占字数**。

### 1.3 跟着记忆一起搬家

- 「备份 / 导出记忆」里包含关系网；
- 「永久记忆」单独导出也包含关系网（不会只剩一堆孤立的句子）；
- **时光胶囊格式升到 v4**，关系网一起打包。**读旧胶囊（v1~v3）照样能装**，只是里面没有关系网。

### 1.4 配置在哪

设置里对应五个开关（`config.json`）：

| 键 | 默认 | 说明 |
|---|---|---|
| `kg_enabled` | `true` | 总开关，关掉就完全不查关系网 |
| `kg_hops` | `2` | 最多走几跳（1~3）。调大能答更绕的问题，但可能塞进无关内容 |
| `kg_build_enabled` | `true` | 是否给老记忆补建图 |
| `kg_build_interval_min` | `1440` | 补建图的间隔（分钟，30~10080） |
| `kg_build_batch` | `30` | 每次补多少条（20~50） |

### 1.5 坏了会怎样

**不会怎样。** 图谱的每一步都是「失败就当我没说」：

- 没装 `networkx` → 自动降级成简易邻接表，功能照用；
- 建图线程抛异常 → 打一行 WARN 日志，下一轮再来；
- 数据库还没建表 → `Memory()` 启动时顺手建，建不了也不拦启动。

清空某个人的永久记忆时，他在图里的点和线**一起清掉**，不会留孤岛。

## 二、自定义音色（声音克隆）

### 2.1 它是什么

以前只能用内置的 edge-tts 音色（晓晓、云希那些）。V1.8.0 可以**接自己的 TTS 服务**，
用一段 5~15 秒的参考音频，让它发出「像你」的声音。

它用的是**外部服务**，程序本身不带声音克隆模型（那玩意儿几个 GB）。支持的协议：

| 格式 | 常见对应 |
|---|---|
| `gpt_sovits` | GPT-SoVITS 的 `/tts` 接口 |
| `cosyvoice` | CosyVoice |
| `fish` | Fish Speech |
| `openai` | 任何 OpenAI 兼容的 `/v1/audio/speech` |
| `simple` | 自己写的小服务，收 JSON 返音频 |

### 2.2 怎么配

设置 → **音视频** → 语音卡片下面的「**自定义音色**」：

1. 勾上 **启用自定义音色**；
2. 选 **格式**；
3. 填 **服务地址**（完整的 URL，例如 `http://127.0.0.1:9880/tts`）；
4. 点「**选择参考音频**」上传一段 5~15 秒的干净人声（wav/mp3 都行，**上限 30MB**）；
5. 如果有需要，填 **参考文本**（参考音频里说了什么）和 **voice_id**；
6. 点「**保存设置**」，再点「**试听一句**」。

试听时会念「这是一句试听，听听像不像我。」

### 2.3 最重要的设计：**它挂了会自己退回去**

自定义音色是**优先**，不是**唯一**。合成顺序是：

```
自定义音色 → edge-tts → SAPI（系统语音）
```

任何一步失败都**静默降级**到下一个，所以：

- 你的 TTS 服务没开、地址填错、端口不通 → 听到的还是正常声音，只是**没有克隆效果**；
- 界面上会明确告诉你：`⚠ 自定义音色没用上，已退回 edge`，
  试听时还会补一句「这次听到的不是克隆的声音」；
- **永远不会出现「说不出话」**。

### 2.4 配置项

| 键 | 默认 | 说明 |
|---|---|---|
| `custom_enabled` | `false` | 启用 |
| `custom_url` | `""` | 服务地址（完整 URL） |
| `custom_format` | `gpt_sovits` | 上面那 5 种 |
| `custom_ref_audio` | `""` | 参考音频路径（存在 `<数据目录>/voices/`） |
| `custom_ref_text` | `""` | 参考音频对应的文字 |
| `custom_voice_id` | `""` | 服务端的音色 ID |
| `custom_model` | `tts-1` | OpenAI 格式用 |
| `custom_token` | `""` | 需要鉴权时填，走 `Authorization: Bearer` |
| `custom_lang` | `zh` | 语言 |
| `custom_voice_name` | `""` | 界面上显示的名字（比如「我的声音」） |
| `custom_timeout` | `30.0` | 超时秒数（5~120） |

### 2.5 常见问题

**换了参考音频，声音还是老的？**
不会。缓存 key 里混了参考音频的路径和修改时间，**换文件后老缓存自动失效**。

**服务返回的是 JSON 不是音频文件，能用吗？**
能。会依次尝试 `audio` / `data` / `audio_base64` / `wav` / `result` 这几个字段做 base64 解码。

**上传的音频文件名是中文，会不会变成下划线？**
不会，中文文件名原样保留（`我的声音.wav` 就是 `我的声音.wav`）。

**为什么上限只有 30MB？**
参考音频**不是越长越好**。5~15 秒、无背景音、无混响的一段最像。太长了服务端反而容易失准。

## 三、这一版没有做的

- **图谱可视化界面**：暂时只有一行统计（实体数 / 关系数），画关系图留到下一版；
- **实体消歧**：「张三」和「小张」目前是两个点；
- **谓词同义词合并**：「养了」和「养着」是两个谓词。

这三样都需要模型参与判断，误合并的代价比不合并大，所以先不做。
