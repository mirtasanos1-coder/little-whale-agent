# 小鲸鱼 Agent 控制台 V1.1.1 更新说明

> 正式版 · v1.1.1 · 作者 Ruao
> 这一版解决的问题只有一句：**让它回得像个人，而不是一个按格式回话的接口。**

---

## 一、升级后先做这四件事

1. **看一下设置 →「聊天与回复规则」**（新卡片）：引用、叫名字、上线打招呼三条规则都在这里，改完不用重启 Agent。
2. **模型页 →「按顺序测一遍」**：会依次查 QQ 接入 → 模型服务 → 出话 → 出图 → 读图 → 动态权限，「卡在哪一步」直接写在下面。测完点「清理测试数据」，测试留下的用量记录、学习条目、测试图一次清掉。
3. **顶部「一键启动」**：NapCat → 本地模型服务（Ollama 会自动找 `ollama.exe` 起服务）→ Agent，按顺序拉起来。
4. **想让它自己学**的话：设置里 `learn_enabled` 开着，写完日记会自动学一次；想指定学什么就去「学习」页把模式切到「按我写的条件学」，条件文本框会一直留在页面上。

## 二、它现在「更像人」在哪

| 以前 | 现在 |
|---|---|
| 下午一点你说「早上好」，它回「早啊！今天阳光不错」 | 它知道你这边是**下午 1 点**，会当成你刚睡醒/开玩笑，自然地接一句 |
| 每条回复都顶着一条灰色引用，像客服 | 紧挨着的一两条直接回，**隔了两条以上才引用**；设置里能调，0 = 每条都引用 |
| 群里必须 @ 它 | 叫「小鲸鱼 / 鲸鱼 / 人设名字 / 人设外号」就行，不用 @；外号在设置里加 |
| 你连发三条一样的，它回三条 | 90 秒内同一句不重复回；连发会被当成一次情绪反应 |
| 一句「你是猪」它回一篇小作文 | 规则里写死了：一次只回一条、不复读、默认 1~3 句、懒得接就短句 |
| 刚上线它干等着 | 7~23 点之间上线会主动给绑定账号发一条，内容由**人设 + 时间 + 记忆**决定 |
| 主动消息只能靠人设猜 | 设置 → 主动回复里能写一句「主动消息的额外要求」，会拼进问候/查岗/关心计划/群里冒泡四处 |

## 三、人设：一个字段一个格子

以前人设是一大段文本，想改一个「口头禅」得从头翻。
现在人设卡按字段填：姓名 / 昵称 / 性别 / 年龄 / 身份 / 性格 / 说话风格 / 口头禅 / 雷区 / 背景 / 第一句 / 说话示例 / 正文。

- 口头禅、雷区用逗号顿号回车分隔就行，会自动拆成列表；
- 说话示例一行一条，写 `对方：在吗 | 你：在。` 就够，也可以贴 JSON 数组；
- 拼提示词时先给它一小块「【角色设定】+【说话示例】」，再读正文——先知道「这是谁、怎么说话」，再看长文。

**顺手修掉一个老 bug**：在卡片列表点第二张卡，右侧编辑区全空。原因是点一下只拿了「列表摘要」，摘要里没有人设正文。现在点一下就去取完整卡片。

## 四、新标签页：「学习」

它现在会自己攒经验了，经验存在单独的 `learn.db` 里（不跟记忆、日记混在一起）。

- 每条经验有：标题、内容、**触发条件**（「当……时」）、标签、开关、用到次数；
- 来源分四种：自己学的 / 你按条件让它学的 / 学画画学到的 / 你手动加的；
- 学习页可以单选，也可以多选**并行应用**；可以编辑、停用、删除；
- 手动模式下的**条件文本框会一直显示**，应用方案之后也不会被清空；
- 这些经验会以「- 当X时：Y」的形式悄悄进系统提示词，它不会跟你炫耀「我学到了」。

---

## 五、新标签页：「画图」

- 可以自己给提示词、挑尺寸（最高 720P）、挑模型，点「立刻画一张」；
- 模型也会自己判断要不要配图：按人设、记忆和你聊的内容决定（`draw_auto` / `draw_chance`）；
- 画成功的图会留在画廊里，**测试图可以直接删**；
- 「像小孩学画」：每学会一点，就在「学习」里多一条画画的经验。

> 需要先在设置 →「生图」里把生图开起来（`imagegen_*`），否则画图页会显示不可用。

---

## 六、新标签页：「管理员」

这是给**你自己**用的远程手动挡。

- 默认整块界面是**模糊的、点不动**的，先输暗号才解锁；
- 解锁后可以写「最高权限提示词」：命中暗号时这段提示词真的会进模型，并且**跳过注入防护**（以前只回一句固定话术）；
- 开启最高权限前有 10 秒倒计时确认，开错了很难误触；
- 「诊断」按钮生成一页纸报告：版本、程序目录、数据目录、优先级链、记忆条数、学习条数、暗号状态、日志尾——可复制、可导出 txt，出问题直接发这份。

> 暗号绑定当前电脑/用户；换电脑后需要重新设一次。

## 七、启动顺序检测：坏了能自己查

模型页新增「启动前检查」，六步按顺序来：

1. **QQ 接入**：NapCat 在不在跑、端口通不通、WebSocket 能不能连；
2. **模型服务**：优先级链里每一条缺不缺 Key；
3. **测试出话**：真的发一句「你在吗」看回不回；
4. **能不能出图**：画图/生图配置齐不齐；
5. **能不能读图**：视觉模型有没有配；
6. **动态权限**：浏览、点赞、评论能不能用。

第一步不过就停下，并告诉你下一步该点哪。另有：

- **「只查配置（不调模型）」**——不花 token；
- **「清理测试数据」**——测试留下的用量记录、学习条目、测试图，一键删干净。

## 八、好感度与情感感知

- 活人感页多了**好感度看板**：谁最熟、谁在掉、最近的变化一眼看完；
- 它会读对方的情绪（低落 / 开心 / 生气 / 平静），**明显的情绪**才拼一句该怎么做进提示词（不明显一个字都不加，不浪费 token）；
- 情绪也会算进好感度：被安慰、被道谢会涨，被怼会掉。

## 九、记忆和日记的备份

| 项目 | 位置 | 说明 |
|---|---|---|
| 记忆导出 | `memory_backup/` | 手动 / 定时；单位切到「年」，365 天会自动变成 1 年 |
| 记忆自动导入 | `memory_import/` | **把备份文件直接丢进去**，后台每分钟扫一次自动合并；成功的进 `done/`，失败的进 `failed/` |
| 日记备份 | `diary_backup/` | 和记忆分开存；支持导出、从文件夹批量导入 |

- 导入区新增「刷新 / 确认文件放对了没」；
- 时间单位只认数字，切单位时会自动按总时长换算（365 天 ↔ 1 年）；
- 定时上限 365 天。
- 记忆页不再挤成两半：左边是子页导航 + 说明，右边的列表区和备份卡中间有一条**可以上下拖的分割条**（双击恢复默认，下次打开还是你拖的样子），备份卡自己右下角也能拉高。

## 十、界面：白框、托盘、图标

- 窗口顶部那条**白标题栏没了**（改成深色，拖拽和缩放照旧）；
- 关窗口默认**最小化到托盘**：单击托盘图标回主界面，右键有「显示主界面 / 启动 Agent / 退出」；
- 程序和托盘图标换成**自己画的鲸鱼**，不引用任何第三方图。

> 托盘需要 `pystray`：`pip install pystray pillow`。没装不会崩，只是关窗口不会缩到托盘。

## 十一、安全

- 「安全策略」相关实现（密钥生成、管理员加密等）现在单独放在 `secure_core` 里，**开源包里只发编译后的 `.pyc`**，并附一份说明告诉人怎么自己重写；
- 你的旧密钥和旧签名仍然能解/能验，不会因为升级打不开；
- 清单签名命中旧密钥时会提示「签名正确（旧密钥，建议重新打包）」。

## 十二、这次修掉的问题

1. 人设卡切到第二张就空白（只剩标题）；
2. 每句都引用、群聊里复读对方原话；
3. 时间感知形同虚设，下午说「早上好」它也顺着说早上好；
4. 群聊里没 @ 就不回；
5. 测试/调试留下的用量记录、学习条目、测试图没法清理；
6. 记忆页太挤，子页和备份卡全堆在一个页面里；
7. 窗口顶部白框刺眼；
8. 管理员暗号开了但**没有任何界面**，只能靠远程发暗号；
9. 日记没有独立备份，和记忆混在一起。

---

## 十三、已知限制

- 一次回复最多 **1 条消息 + 1 张图**；连发多条会被合并；
- 画图效果取决于你配的生图模型（本地或云端）；
- 好感度/情绪是轻量规则 + 提示词引导，不是严格的心理学模型；
- 管理员暗号绑定本机，换电脑需要重设；
- 托盘功能需要 `pystray`，纯净环境不会自动装。

---

## 十四、出问题怎么办

1. **打不开 / 白屏**：控制台里点「刷新」，或退出重开；日志在 `data/logs/`。
2. **不回消息**：模型页点「按顺序测一遍」，看卡在第几步；再到设置 →「QQ 接入」确认 NapCat 端口。
3. **说话不像人设**：设置 →「人设与风格」检查人设卡字段（性格、口头禅、雷区、说话示例最好都填一点）。
4. **画不出来**：设置 →「生图」里把生图开起来，确认模型支持出图。
5. **其他**：管理员页 →「诊断」→ 复制报告发给作者。
