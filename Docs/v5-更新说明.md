## 一、永久记忆会「顶掉旧事实」了（最重要）

**你上次的原话**：

> 我说了：不对，我和她在一起的日子是 24 年 11 月 27 日，但是旧纪录没有被替换，改一下

**之前为什么不行**：v4 写永久记忆时只判「内容一模一样」才去重。差一个字就算两条新的，
所以「纪念日是 2024-11-27」和「纪念日是 2023-11-27」会一直并存，两条互相矛盾。

**现在怎么改**：

1. 每次提炼记忆前，会把**该账号已有的记忆连编号**一起给模型看：

   ```
   已有的长期记忆（要更新哪条，就把编号填进 replaces）：
   #1 (relation) 与名为梅梅的人是恋爱关系，纪念日是2024年11月27日
   #2 (preference) 喜欢打游戏
   ```

2. 模型判断出"这是在纠正 #1"，就返回 `"replaces": 1`，程序把 #1 标成「已被替换」，新的生效。

3. 模型没给 `replaces` 时还有**启发式兜底**：归一化骨架相同 / 一方是另一方子串 /
   2-gram 重合度 >= 50% / **双方都含 4 位以上数字且重合度 >= 22%**（专门为纪念日、
   生日、门牌号这类数字改口准备的一条）。

4. **旧条目不删**，只标 `superseded`，界面上能看到"已被替换"，想追溯还有。

**你可以自己验证**：

- 界面「记忆查看 → 永久记忆」
- 说一句纠正的话，比如「不对，我生日是 3 月 5 日」
- 等几秒刷新，旧的会变成灰色「已被替换」，新的在最上面

## 二、记忆怎么记，你说了算（三档策略）

设置 → 记忆策略 →「怎么记」：

| 选项 | 什么意思 | 什么时候选 |
|---|---|---|
| **模型自己判断**（默认） | 每轮聊完，让模型判断"这轮有没有值得长期记的"，有才写 | 推荐。省 token，也不把废话记进去 |
| **每条都记** | 每条消息都试着提炼，模型说没有就用规则硬抽 | 想尽可能多记，不怕噪音 |
| **只存临时缓存** | 完全不写永久记忆，只保留最近几十条对话当上下文 | 只想当聊天机器人，不要长期记忆 |

同一张卡上还有：

- **新事实顶掉旧事实**（默认开）—— 关掉就回到 v4 行为，两条都留着
- **每天自动导出记忆备份**（默认关）—— 开的话每天导一份到 `memory_backup/`，保留最近 7 份

## 三、模型可以接云端了（带用量看板 + 超限拦截）

以前只能连本地 LM Studio。换台没有显卡的电脑就没法用。

**现在**：设置 → 模型设置 → 模型来源，选一个填 Key 就行，内置 8 家预设：

| 预设 | base_url | 说明 |
|---|---|---|
| 本地 LM Studio | `http://127.0.0.1:1234/v1` | 免费、离线、隐私最好 |
| DeepSeek | `https://api.deepseek.com/v1` | 便宜，中文好 |
| OpenAI | `https://api.openai.com/v1` | 贵 |
| Kimi（月之暗面） | `https://api.moonshot.cn/v1` | 长上下文 |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | 国内 |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 国内 |
| OpenRouter | `https://openrouter.ai/api/v1` | 一个 key 用所有模型 |
| 硅基流动 | `https://api.siliconflow.cn/v1` | 国内聚合 |
| 自定义 | 自己填 | 任何 OpenAI 兼容端点 |

**切完不用重启 Agent** —— 界面会通知后台进程热切换。

### 用量看板

设置 → 模型设置 → 用量看板，能看到：

- 今日云端 / 今日本地：各花了多少 token、调用几次
- 上限使用率：百分比 + 进度条（>=60% 黄，>=100% 红）
- 保护状态：正常 / 接近上限 / 已拦截
- 最近 7 天：按天分本地/云端
- 今日分用途：聊天 / 记忆提取 / 说说 / 日记 / 补回，各花了多少

### 三层防异常用量

| 层 | 什么时候 | 做什么 |
|---|---|---|
| 1 | 调用**前** | 今日云端超 `usage_daily_limit`（默认 20 万）→ **请求根本不发**，一个 token 都不花 |
| 2 | 调用**中** | 到 80% 打一条 WARN 日志，界面百分比变黄 |
| 3 | 界面 | 到 100% 进度条变红、状态变「已拦截」 |

想完全不限制：把 `usage_daily_limit` 设成 `0`，或关掉「用量保护」。

> **Key 存在哪**：只写本机 `config.json` 的 `cloud_api_key`，**不进开源包**，也不显示明文（界面只给 `sk-abc****wxyz`）。

## 四、QQ 接入（NapCat）集成进来了

以前要自己装 NapCat、找 `napiLoader.bat`、点登录。现在设置 → QQ 接入：

那张卡会直接告诉你状态：

```
✅ NapCat 正在运行，已登录
   NapCat 正在运行，QQ 接入正常
   目录：D:\napcat-fw
   启动器：D:\napcat-fw\napiLoader.bat
   HTTP 3000 · WS 3001
```

四个按钮：**重新检测 / 启动 NapCat / 打开目录 / 检查最新版本**（能一键下载安装到 `数据目录/napcat`）。

**启动时自动检测**三档（默认「只在第一次启动时检测」，不烦人）：

| 选项 | 行为 |
|---|---|
| 只在第一次启动时检测（默认） | 装过一次就不再问 |
| 每次启动都检测 | 每次开都检查一遍 |
| 完全不检测 | 自己手动起 |

## 七、记忆可以导出 / 载入 / 重编译

记忆查看 → 永久记忆，多三个按钮：

| 按钮 | 作用 |
|---|---|
| **导出记忆** | 存成 JSON 到 `memory_backup/memory_yyyymmdd_HHMMSS.json`（含永久记忆 + 日记 + 事件，**不含临时对话**） |
| **载入记忆** | 从 JSON 恢复，两种模式：`merge` 追加（冲突的旧条目标已替换）/ `replace` 先清空再整批写入 |
| **重编译** | 把旧版本写进库的数据整理一遍：补 `norm_key`、去掉重复的、把 v4 之前的老表数据搬过来。**跑之前自动备份** `memory_backup/memory_before_rebuild_*.db` |

**为什么需要重编译**：v4 以前的永久记忆没有 `norm_key`（冲突检测的归一化骨架），
不加这一步，旧数据永远检测不到"说的是同一件事"。

## 八、卸载时可以选择保留数据

设置 → 卸载与数据保留：

- **保留**（默认）—— 卸载只删程序文件，`memory.db` / `config.json` / `personas.json` /
  `stickers/` / `themes/` / `icons/` / `memory_backup/` 全都留着。重装回来记忆还在。
- **不保留** —— 连数据一起清。

这个开关只是**把卸载说明写成对应的文字**，不会自己删任何东西。

## 九、顺手修掉的问题

| 问题 | 原因 |
|---|---|
| 设置页「新公告弹窗」等三个开关明明开着却显示关闭 | 前端读 `settings.notice['notice_popup']`，但后端返回的字段叫 `popup` → 全是 `undefined` |
| 模型来源切到云端，下面那行说明还写"本地 LM Studio，不计费" | 说明文字取的是「已保存的提供方」而不是「下拉框当前选的」 |
| 切回本地后模型名变空 | 本地预设没有模型列表，代码把输入框清空了 |
| 服务地址输入框一直空着（只显示灰色提示） | 后端没返回 `resolved` 这一层，前端读 `undefined` |
| 「记忆 → 重编译」预览说"0 组重复"但明明有 | 按 `norm_key` 列 GROUP BY，旧行该列是 NULL 全被忽略 |
| 调试按钮「恢复全部公告」点了没反应 | 只清了「不再提示」，没清「已读」，未读数还是 0 |
| 开关传 `"0"` / `"false"` 反而变成开启 | `bool("0") == True`，改成 `_coerce_bool()` 白名单 |

## 十一、升级后要做的三件事

1. **记忆 → 重编译** 跑一遍（旧数据的 `norm_key` 要补，不然冲突替换对旧条目无效）
2. 检查 **设置 → 模型来源** 是不是还指着本地 LM Studio；想用云端就在这一步填 Key
3. 检查 **设置 → 记忆策略** 是不是「模型自己判断」（默认就是，除非你之前把配置改过）
