# 小鲸鱼 QQ Agent v8 更新说明

> 更新日期：2026-10-22
> 从 v7 升级上来只需要**解压覆盖**（`config.json`、`personas.json`、`memory/`、`stickers/`、`themes/`、`backgrounds/`、`langs/`、`icons/` 都不会被覆盖）。
> 这一版的核心：**说话时机终于对了**（设了几点发就几点发）、**多了好感度**、**英文界面真能用**、**能一键卸载**。

---

## 一、升级后要做的三件事

1. **去「设置 → 主动回复」看一眼** —— 如果你以前抱怨过「设了时间不发」，这一版就是修它：

   - 「安静多久才发」填 `0` = **到点就发，完全不看静默**；
   - 想做 1 分钟自测就填 `0.02`（≈1 分钟），加一条 1 分钟后的测试条目，等两分钟就能看到；
   - 想让她「像真人一样挑时候」，把判定方式改成「让模型自己判断」。

2. **想开启好感度**（可选，默认关）—— 「设置 → 好感度」打开总开关 → **重启 Agent** → 「活人感」页会多一个看板。

3. **想用英文界面** —— 「设置 → 背景与语言」选 English。这一版修好了之前「切了一点变化都没有」的两个 bug。

## 二、主动回复重做（这一版最重要的修复）

### 2.1 之前为什么「设了不发」

老逻辑是：到点之后**无条件**再检查一次「对方是不是已经安静了 2 小时」。
你刚跟我聊完天，马上加一条 1 分钟后发的测试条目 → 静默时间只有 0 小时 → 被跳过 → 看起来就是「设了不响」。

### 2.2 现在怎么判定

| 设置项 | 默认 | 说明 |
|---|---|---|
| 安静多久才发 | 2 小时 | 支持小数。**填 `0` = 不看静默，到点就发**（测试条目就这么用） |
| 怎么判定 | 安静够久就发 | 另一个选项是「让模型自己判断」：把最近 8 条对话给它，让它回「发」或「不发」 |
| 多久检查一次 | 30 秒 | 10–3600 秒 |
| 关心计划也看静默 | 关 | 关 = 计划到点就发，不管刚聊过没有 |

### 2.3 怎么知道它为什么没发

日志里会写清楚：

```
[主动回复] 对方刚聊过（静默 0.3h < 要求 2h）→ 跳过
[主动回复] 模型觉得现在别打扰 → 跳过
[主动回复] 模型觉得可以发 → 发送
```

再也不用猜了。

## 三、好感度系统（可选，默认关闭）

### 3.1 开启后会怎样

- 每个人有一个分数，按 7 档关系显示：**陌生人 → 认识的人 → 熟人 → 朋友 → 好朋友 → 知己 → 特别的人**
- 分数会影响**回话的语气**（越熟越随意、越会开玩笑），但**不会把分数说出来**
- 不想让它知道具体数字 → 关掉「把分数告诉模型」，只给关系等级

### 3.2 怎么加分

| 事件 | 默认变化 | 可调范围 |
|---|---|---|
| 聊一句 | +1 | 0–10 |
| 说了让人开心的话 | 再 +3 | 0–20 |
| 说了难听的话 | -1（等于好话增量的一半） | — |
| 一天没来往 | -1 | 0–20（填 0 = 不掉） |
| 上限 | 1000 | 10–100000 |

### 3.3 看板在哪

「活人感」页底部：谁、多少分、什么关系、聊过多少句、清零按钮。
右上还有「手动设分」和「全部清零」。

## 四、其他新功能

### 4.1 界面卡片透明度

「设置 → 外观」有滑块（20%–100%）。拖动立刻预览，点「保存」才写进配置，重启不丢。

### 4.2 英文界面终于能用了

之前切 English 一个字都不变，是两个 bug 叠在一起：

1. 后端拿界面翻译的函数**不收语言参数**，切完语言前端还是拿的旧表；
2. 数据目录里那份 `en-US.json` 只是个**空样板**，程序自带的 433 条翻译根本没被读到。

现在两个都修了：按语言码返回 + 「程序目录 + 数据目录」合并（缺的用程序自带的补）。
另外中文界面下**一个字都不会被动**（中文翻译表是空的），动态加载出来的新元素也会自动翻译。

### 4.3 公告改成堆叠卡片

以前公告一条一行往下排，五条就把页面顶掉半屏。现在：

- 最多 **4 张**卡片错开叠在一起，只有最上面那张能点；
- 「知道了」= 标记已读（以后不再出现）；「下一条 ↓」= 翻下一张；
- 已读 / 已关闭的公告**不再显示**；
- 不喜欢就看「设置 → 公告」，关掉「堆叠显示」，退回老的一行一条。

### 4.4 说说每天发几条自己定

「活人感 → 说说」：

- 可以分别设**每天最少 / 最多**几条（0–50）；
- 预设按钮：`0 / 1 / 3 / 5 / 10 / 15 / 20`；
- 填超过 30 会弹确认框提醒「**设置太多会出问题的~**」；
- 填超过 50 直接不让存；
- `0 ~ 0` = 一条都不发。

### 4.5 日记升级：她真的会「回忆这一天」

每天到点（默认 23 点，可改成任意整点），她会把四样东西合起来写一篇日记：

1. 自己的人设
2. **今天新记住的长期事实**
3. **以前记下的长期事实**（所以日记有连续感，会提到前几天的事）
4. 今天的聊天记录

「手动生成」随时能让她现在写一篇；**没绑定的账号也能手动写**（只是不进永久记忆库）。

### 4.6 生图直接用当前模型设置

不用再单独填一套生图 API 了：勾上「用当前模型」，它会顺着你的**模型优先级列表**找第一个支持生图的服务；
当前模型不支持就自动换列表里的下一个。

### 4.7 关心计划认得更准，关掉就不再显示

- 提取事件时会**带上最近几条对话**（「他刚说周六体检，然后回了个『对』」这种也能认出来）
- 自动去掉「我明天9点考试」里的「我」，查岗话术不会变成「我明天9点考试——后来怎么样啦？」
- 「事情 / 安排 / 那个」这类空泛描述直接丢弃，超过 40 字的也丢
- 关掉关心计划后，「活人感」页那一整块**不再显示**（不留空盒子）

### 4.8 一键卸载

「设置 → 卸载本软件」：

- 先给你看清单：哪些会删、哪些会留；
- **默认留下**：配置、记忆（`memory/`）、人设、表情包、主题、语言包、图标、背景图；
- 取消勾选「保留数据」就连数据一起删（重装等于从零开始）；
- 卸载脚本会等程序退出后再删目录，最后弹一句「卸载完成」；
- 源码版（`python app_ui.py` 跑的）不能自删，只能看清单。

### 4.9 小修

- 绑定账号 / 群号输入框里那个示例 QQ 号**删掉了**（以前容易误以为已经填了）；
- 「主动回复」的提示条不再被卡片盖住；
- 新增 `_selftest_v8.py`（137 项自检）和 `_check_js.py`（前端脚本括号检查）。

```json
{
  "checkin_silence_mode": "fixed",
  "checkin_silence_hours": 2.0,
  "checkin_poll_sec": 30,
  "care_plan_use_silence": false,

  "affinity_enabled": false,
  "affinity_gain_per_msg": 1,
  "affinity_gain_positive": 3,
  "affinity_decay_per_day": 1,
  "affinity_max": 1000,
  "affinity_show_score": true,

  "ui_panel_alpha": 86,
  "notice_stack": true,

  "moment_min_per_day": 1,
  "moment_max_per_day": 10,
  "diary_hour": 23

```

| 键 | 范围 | 一句话 |
|---|---|---|
| `checkin_silence_mode` | `fixed` / `model` | 只看静默 / 再让模型判断 |
| `checkin_silence_hours` | 0–72（小数） | **0 = 到点就发** |
| `checkin_poll_sec` | 10–3600 | 多久扫一次 |
| `care_plan_use_silence` | bool | 关心计划要不要也看静默 |
| `affinity_enabled` | bool | 好感度总开关 |
| `affinity_gain_per_msg` | 0–10 | 每聊一句加多少 |
| `affinity_gain_positive` | 0–20 | 好听话额外加多少 |
| `affinity_decay_per_day` | 0–20 | 每天掉多少（0 = 不掉） |
| `affinity_max` | 10–100000 | 分数上限 |
| `affinity_show_score` | bool | 要不要把分数告诉模型 |
| `ui_panel_alpha` | 20–100 | 卡片透明度 |
| `notice_stack` | bool | 公告堆叠显示 |
| `moment_min_per_day` | 0–50 | 每天最少几条说说 |
| `moment_max_per_day` | 0–50 | 每天最多几条说说 |
| `diary_hour` | 0–23 | 每天几点写日记 |

> 改了 `config.json` 要**重启 Agent** 才生效；界面上点「保存」会提示。

## 六、常见问题

**Q：设了主动回复还是不发？**
依次看：①「安静多久才发」是不是比你们刚聊完的间隔还大 → 填 `0` 试试 ②判定方式是不是「模型判断」，而模型每次都说不发 → 改回「安静够久就发」③日志里搜 `[主动回复]`，原因都写在里面。

**Q：好感度看板不见了？**
总开关默认是关的；打开后要**重启 Agent**；关掉开关时卡片会整块隐藏（不是出错）。

**Q：切英文还是有几句是中文？**
翻译表里没有的句子会**自动退回中文**（这是设计好的兜底）。想补翻译：编辑 `langs/en-US.json` 的 `ui` 段，键写中文原文、值写英文，例 `"保存": "Save"`。

**Q：公告一下子少了好几条？**
已读的公告不再显示。想重看 → 通知中心里把它们标记成未读，或删掉 `agent_state.json` 里的 `notice_read`。

**Q：说说一条都发不出去？**
`moment_min_per_day` 和 `moment_max_per_day` 不能都是 0；另外模型判断「现在没话说」时也会跳过（这是故意的，不硬凑）。

**Q：卸载后发现记忆还在，是不是没删干净？**
那是「保留数据」默认勾上了（故意的：重装能接着用）。想彻底删干净 → 取消勾选再卸一次，或手动删 `memory/`。

## 七、这一版修掉的 bug 清单

| 问题 | 根因 | 修法 |
|---|---|---|
| 生图开关点了没反应 | `save_settings` 白名单少了 `imagegen_use_current`，前端传上来被静默丢弃 | 同时补 `DEFAULTS` / `_BOOL_KEYS` / 白名单三处 |
| 1 分钟后发的测试条目到点不发 | 无条件要求静默 2 小时 | 静默门槛变成配置，`0` = 不看静默 |
| 切 English 界面毫无变化 | `get_ui_lang()` 不收参数 + 语言目录只认一个（数据目录那份是空样板） | 接收 `code`；程序目录/数据目录按 code 合并 |
| `UNIQUE constraint failed: affinity.user_id` | 好感度用裸 `INSERT`，第二次加分撞主键 | `INSERT OR IGNORE` + `UPDATE` |
| 手动生成日记提示「未绑定」 | guard 把 force 也拦了 | `force=True` 允许未绑定写 |
| 日记读不到当天聊天 | 会话 key 写成 `private:{uid}` | 统一 `private_{uid}`（下划线） |
| v8 的日记逻辑完全没生效 | `diary.py` 里有两个同名 `write_diary_for`，Python 取了后面那个 | 删掉前面的空壳定义 |
| 解析「发 / 不发」永远判成「发」 | 「不发」两个字里也含「发」 | 先判「不发」再判「发」 |
| 主动回复提示被卡片盖住 | 公告一条一行往下堆 | 公告改堆叠卡片 |
| 关心计划关了还留一块空白 | 渲染时没判断开关 | `care.enabled=false` 时整块隐藏 |
