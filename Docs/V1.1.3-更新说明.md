# 小鲸鱼 V1.1.3 更新说明（人话版）

> 这版没加很多花活，主要是把你截图里那几处「看着不对」掰回来，再把情感、上下文、启动几条链路补成能用的样子。

## 一、先验这两条（修的是真 bug）

1. **设置 → 外观**：把「无边框窗口」或「关窗口时缩到托盘」点开，切到别的页再回来、或刷新界面——以前会自己弹回「关」，现在应该保持「开」。
2. **管理员页**：以前打开有一片按钮失灵（少了分号，整段脚本崩了），现在应该都正常。

## 二、重启不再靠猜

改完「无边框 / 托盘」这类要重启才生效的项，会直接弹：

> **XX 功能需要重启生效，要重启吗？**
> 「等不及了，即刻重启！」　「先不要吧」

点前者会真的把 Agent 结束再拉起（不是只关窗口），十几秒回来。

## 三、「启动顺序判定」可以自己排了

六步（QQ → 模型 → 出话 → 出图 → 读图 → 动态）带序号，能上下移、能拖，保存后按你的顺序跑。
一键启动前先看 QQ 是否已在跑、本地模型端口是否已通——在跑就跳过，不再重复拉起，也不弹黑框。

## 四、新页：情感中枢

- 三档口径：**常规细腻型 / 直男理性型 / 傲娇型**。
- 每条消息判一次：情绪、权重（0~100）、姿态建议。权重高的先回（私聊「我失恋了」90+，群里「哈哈哈」10+）。
- 最多等 0.9 秒；判不出来就静默用本地词表，日志标「本地」，不卡回复。

## 五、群聊终于「记得前情」

每个群默认记最近 20 条（可调）。被 @ 或叫名字时取「@ 前几句 + @ 后几句」一起看；空档超 5 分钟或连续 10 条刷屏自动截断。

## 六、伴侣模式（默认关，要自己开）

- 和好感度是两回事：好感度管「熟不熟」，伴侣管「是不是这一层」。
- **群里**：开着就强制注入「公开场合」警告——严禁撒娇、暧昧、占有欲，最多轻微傲娇护短。
- **私聊**：好感度够（默认 600）或你写了补充要求，才放开亲密口吻。

## 七、学习变细了

类型扩成 9 类：说话方式 / 知识 / 共情方式 / 细微情绪 / 认知·世界观 / 价值观 / 习惯 / 人际相处 / 感官偏好。
「认知、价值观」会写进角色底色，所以加了红线：含极端、违法、涉黄涉暴内容的条目**直接拒收**。

## 八、外观与语音

- 新主题 **金秋**：低饱和金黄橙红 + 枫叶银杏飘落。
- 雪夜主题的卡片上沿做成真·雪堆（模糊 + 阴影）。
- 切主题 0.8 秒过渡，像雪慢慢化开。
- **实验性语音**：`pip install edge-tts` 后打开「语音回复」，短句会补一条语音（默认只对私聊、超 60 字不转）；没装只打日志。

## 九、系统自检

控制台右上角「系统自检」：一键查数据库 / 记忆 / 模型 / 依赖 / 安全 / 插件 / 网页版，出一份带建议的报告。

## 十、怎么确认装的是这版

- 左上角小字应是「正式版 · v1.1.3」；
- 顶部多一个「情感中枢」标签；
- 「无边框窗口」点开不会再自己弹回去；
- 控制台右上角有「系统自检」按钮。

对不上多半是没重启主程序。
