# 小鲸鱼 QQ Agent V1.6.0 发布说明

> 发布日期：2026-10-28
> 产物：安装程序 `小鲸鱼_x64-setup.exe`（416.29 MB）· 绿色版 `小鲸鱼_V1.6.0_绿色版.zip`（415.16 MB）· 开源包 `小鲸鱼_V1.6.0_开源包.zip`（6.47 MB）
> 从 V1.5.3 升级：安装包直接覆盖安装；绿色版解压覆盖即可（`config.json`、`personas.json`、`memory/`、`stickers/`、`themes/`、`backgrounds/`、`langs/`、`icons/`、`runtime/` 都不会被覆盖）

这一版**不加新功能**，只把「越用越乱」的地方收干净，外加修掉一个老毛病。

一句话：**导航从 14 个挤成一条变成 5 大类**，**开大功能前先提醒一句性能**，**删掉跑不动的「程序生图」**，**点退出终于真的退出**。

---

## 一、升级后请先看这三处

1. **导航变了**：顶上只剩 5 个按钮 —— 控制台 / 模型与引擎 / 灵魂与记忆 / 实验室·扩展 / 系统设置。
   原来的 14 个页签一个都没丢，全在大类下面的第二行。
2. **消耗预估默认关着**：想看得去「系统设置 → 设置 → 消耗预估」自己打开。以前它每次进设置页都要算一遍、拉一屏表格，其实多数人看完一次就够了。
3. **开大功能会先问一句**：音视频通话、自动说说、本地向量记忆 —— 开启时会弹一句「可能占一些性能」，点【知道了】才真的开。**这不是安全确认**，只是提醒。Agent 那套另算：启用前要读完 10 秒风险页并勾选，之后每个危险动作再单独弹窗问你。

---

## 二、导航：14 个页签 → 5 大类 + 二级页签

以前 14 个页签平铺在一行，窗口一窄，最后几个就被挤到看不见（`Agent` 页最容易中招，V1.5.1 为它加过横向滚动，但滚动条本身也很难发现）。

| 大类 | 下面的子页 |
|---|---|
| 控制台 | 控制台 |
| 模型与引擎 | 模型 / 语音 |
| 灵魂与记忆 | 人设 / 记忆 / 情感中枢 / 好感度 / 学习 / 自省 |
| 实验室·扩展 | 音视频 / Agent / 动态 / 画图 |
| 系统设置 | 设置 / 管理员 |

行为说明：

- 点大类 = 进这一类的第一个子页；之后用第二行的子页签横向切换（子页签多了会横向滚动，不会挤掉）。
- 大类按钮上那条会滑的小横条（tab ink）也跟着一起走，点哪亮哪。
- 设置里那些「去设置 XXX」的跳转按钮照旧能用：它会先切到对应大类、再定位到那张卡片并高亮一秒（比如「启动顺序判定」里的两个按钮）。
- 窄窗口下 5 个大类只占 14~398px，14 个子页签合计 782px，1123px 的正文宽度正好放得下，不再有横向溢出。

## 三、开大功能前的性能提醒

| 功能 | 什么时候问 | 关键文案 |
|---|---|---|
| 音视频通话 | 打开「语音通话」总开关、或点「启动微服务」时 | 会拉起本机的音视频微服务（一个独立进程），常驻约 130MB |
| 自动说说 | 打开「自动发说说」时 | 会定时让模型写内容，费 token |
| 本地向量记忆 | 把向量后端从「轻量 / 关键词」改成本地模型或云端时 | 会加载向量模型，占内存 |

细节：

- 弹窗只有【知道了】和【算了】，**不倒计时**，不逼你等。
- 点【算了】= 这次什么都不改（开关不会被动）。
- 同一台机器同一个功能只问一次（确认位记在配置里：`perf_ack_av` / `perf_ack_moment` / `perf_ack_embed`）。
- **它不是安全确认**：Agent 那套是独立的、也更严 —— 启用要先读完 10 秒风险页并勾选，之后每个危险动作再单独弹窗问你。

## 四、「程序生图」已移除

以前画图页有一个「程序画图」按钮：让模型写一段 Py 绘图代码，在本机跑出图片。删掉的原因很实在：

- 模型写的绘图代码十次有七八次跑不通或画出一团色块，失败还要再花一次 token 修；
- 它要 `exec` 一段模型生成的代码，和安全策略一直别扭；
- 真正能用的两条路早就有了。

现在画图只剩三条，都是能出图的：

1. **生图接口**（你有生图模型就用这个，最像样）；
2. **聊天出图**（用会画画的聊天模型，走 `/v1/chat/completions` 的出图能力）；
3. **SVG 生图**（让模型写矢量图，本地渲染成 PNG —— 不依赖任何生图接口，聊天模型能写字就能画）。

画不出来时的提示也改了：不再劝你「再试一次程序画图」，而是直接建议改用 SVG。

## 五、退出与稳定性（这版顺手修的）

| 问题 | 以前 | 现在 |
|---|---|---|
| 还没同意免责协议就点 ✕ | 关不掉，只能任务管理器 | `quit_app` / `win_close` 放进免协议白名单，能正常退 |
| 点「退出」后端退了、窗口还在 | 开托盘时更是永远躺托盘里 | 后端退完 400ms 壳自己 `exit`，实测 **2.8 秒**进程消失 |
| 壳启动后端失败 | 死等 45 秒，还占着单实例锁，再点也没反应 | 20 秒超时 + 3 次重试 + 弹框告诉你原因（附日志路径） |
| `_MEI` 临时目录残留 | 越攒越多，C 盘被塞满 | 启动时清扫 45 秒前的残留，超长路径用 `\\?\` 强删，删不掉只记日志（不再叠后缀） |
| 搜索一次要一分多钟 | 先开浏览器挨个引擎等超时 | 先并发抓结果页（两三秒），抓不到才开浏览器；实测 **82s → 6.6s** |

## 六、已知限制（如实写）

- **打包版不提供网页版控制台**（8765 面板只对源码运行有效）——这是安全决定，不是 bug。
- **macOS / Linux 未实测**，只有 Windows 的安装包与绿色版。
- **托盘开着时点 ✕ 是缩到托盘**（v1.3.0 起的老设计）；想真退出用托盘菜单或界面里的「退出」。
- **虚拟声卡仍需 VB-Cable**：想让对方听到"电脑里的声音"，得自己装一次 VB-Cable。
- **Agent 操控 QQ 还是"本地键鼠"路线**：需要 QQ 窗口在前台，没做协议级（不需要窗口）的操控。
- 人设、记忆、胶囊这些数据都是本机文件，**卸载默认不删**。

## 八、下一轮：`agent.py` 物理拆包（已决定暂缓）

`agent.py` 现在 8300 行、几百个模块级全局量，别的模块到处 `import agent` 再读这些量。真要一次拆成 `a_/b_/c_`，等于同时动 500+ 处引用 —— 改完最容易出现的是「聊天照常、但某个角落悄悄不工作」（关心计划、语音、事件提取这类），而且很难在验收里覆盖到。

所以这一版**不拆**。等 V1.6.0 稳定运行一段时间后单独开一轮，并且按「切香肠」的方式切：先只拆最边缘、最独立的叶子模块（`text_utils.py`、`messenger.py` 这类纯函数），**不动核心 globals**，每拆一刀都跑一遍行为对照。交接说明见 `开发进程文档.md` 第九节。
