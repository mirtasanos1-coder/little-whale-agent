## 这一版你能摸到的东西

1. **它开始「按意思」记东西了**：以前只认关键词，现在你说「那天我不太舒服」，它能捞出「上周三头疼请假」那条。设置 → 记忆里可以关掉或调召回强度。它用的 embeddings 模型会自动从你本机模型服务里挑（名字带 embed 的那个）；没加载就是关键词兜底。
2. **记忆查看页讲清了五层记忆**：运行记忆、摘要、永久、语义、潜意识，各自带什么、什么时候用、大概吃多少 token，都写在页面上。
3. **新 Tab「自省」**：能看到它自己记的笔记、思考存档、记忆衰减；衰减可以设「保留多少天」再手动跑一次，跑之前会告诉你会动多少行。
4. **控制台多了性能面板**：事件循环延迟、内存、CPU、线程数、队列里排了几件事，卡的时候先看这里。
5. **快速对话测试**：控制台里直接问一句，逐字上屏。注意：**QQ 通道只能整条发**，这里做的是「结果到了再逐字显示」，不是假装流式。
6. **伴侣关系能改了**：好感度页的关系表可以直接改等级、写备注、删除；分数自动过线也会升，但你手改的不会被覆盖。
7. **设置页顶部「跳到」**：外观 / 动效 / 聊天规则 / 好感度 / 公告 / 更新 / 安全，一键滚到。
8. **修了几个让人以为「没保存」的毛病**：主动回复等待时间保存不再报错；日志里那些 `_append_log` 的 TypeError 没了；画图保存能成图，程序生图失败会重试。

## 你需要知道的取舍

- 语义记忆用的是**你本机模型服务**的 embeddings；模型服务没开时它会退回关键词匹配，能搜但不那么灵。
- 没有引入 `sqlite-vec` / `onnxruntime`：Windows 打包太容易翻车。代价是万条以上会变慢，源码里留了升级路径。
- 还是那句：QQ 通道不支持流式，所有「逐字」效果都在控制台里。

## 这一轮又补了什么（补丁 2）

- **积雪关不掉了？** 已修：设置里的开关优先于主题，点一下立刻保存。
- **发图 base64 报错**：改成走本地文件路径，更稳。
- **主动回复开了不发**：时段、间隔、每天最多几次，现在真的按你填的来。
- **上线补回**：群/私聊两个开关 + 补几条，都能调。
- **语音**：设置 → 聊天与回复规则 → 偶尔发语音（需要电脑装了 edge-tts）。
- **人设图识别**：新增「看图识图」分工；没配视觉模型时会退化成文字描述，并告诉你该配哪个。
- **向量记忆**：装了 sqlite-vec 会自动用 SQL 加速；也支持把 BGE 模型放进 `models/bge-small-zh/` 离线用。

## 出问题怎么办

- 语义记忆没结果 → 设置里看「语义检索」卡的状态，`keyword` 就是 embeddings 没通。
- 性能面板 CPU 显示 n/a → 没装 psutil（可选依赖，不影响使用）。
- 伴侣关系改不动 → 该行是 `auto=0` 才不会被自动覆盖；确认你改的是关系表而不是好感度分数。
