#弹窗与提示规范（V1.7.0）

本项目从 V1.7.0起，全站弹窗/提示统一走 `window.UI`三个组件。
**新增代码请直接调 `UI.*`；老代码里的 `toast()` / `confirmDialog()` / `promptDialog()` / `riskConfirm()`由兼容层自动接管，不需要改。**

##一、文件结构

|文件 |作用 |
| --- | --- |
| `desktop/src/ui/ui.css` |三个组件的全部样式（只用 CSS变量，自动适配亮色主题） |
| `desktop/src/ui/ui-core.js` |底座：焦点锁定、Esc处理、模态栈、i18n取值、RPC |
| `desktop/src/ui/ui-toast.js` | `UI.toast`轻量提示 |
| `desktop/src/ui/ui-confirm.js` | `UI.showConfirm`阻断警告 + `UI.prompt`输入框 |
| `desktop/src/ui/ui-sign.js` | `UI.showSignDialog`强模态签署 |
| `desktop/src/ui/ui-compat.js` |兼容层：保留旧全局函数名，内部转发到新组件 |

加载顺序（`index.html`第17行起，**必须全部 `defer`**）：

```html
<link rel="stylesheet" href="ui/ui.css">
<script defer src="ui/ui-core.js"></script>
<script defer src="ui/ui-toast.js"></script>
<script defer src="ui/ui-confirm.js"></script>
<script defer src="ui/ui-sign.js"></script>
<script defer src="ui/ui-compat.js"></script>
```

`defer`保证在内联主脚本执行完、`window.toast`等旧函数已经定义之后，兼容层再覆盖它们。

##二、层级（z-index）

|层级 |值 |用途 |
| --- | --- | --- |
| Toast | `100000` |最高，永远可见，但不吃点击（容器 `pointer-events:none`） |
|签署弹窗 | `99999` |强模态，用户必须处理 |
|阻断警告 | `99990` |半透明遮罩 +居中卡片 |
|页面原有弹窗 |40~120 |老代码遗留，未迁移 |

##三、`UI.showConfirm(title, body, options)` → `Promise<boolean>`

阻断式警告框，**点遮罩不关闭**，Esc等同取消。

```js
const ok = await UI.showConfirm(
 '删除这个账号的全部永久记忆？',
 '共1240条永久记忆会被一起删除。',
 {
 okText: '确认删除', //必填：明确动作，禁止「确定/取消/关闭」
 cancelText: '保留记忆', //必填：明确后果，禁止「取消」
 danger: true, // true =确认按钮红色（#dc2626，等价 bg-red-600）
 risk: '此操作将永久删除1240条永久记忆，且无法恢复。', //必填：风险后果
 countdown:10 //可选：危险操作倒计时 N秒才可点
 }
);
if (!ok) return;
```

**按钮文案会兜底**：`okText`若传了「确定/确认/OK/是/好的/取消/关闭」这类模糊词，
组件会自动改成「确认+动作」并 `console.warn`；`cancelText`同理变成「暂不+动作」。

**默认焦点落在安全按钮**（取消/保留），Tab在弹窗内循环，不会跑到背景。

`options`全部字段：

|字段 |说明 |
| --- | --- |
| `okText` / `cancelText` |按钮文案，禁止模糊词 |
| `danger` |默认 `true`；`false`时确认按钮用主色 |
| `risk` |风险后果，始终渲染，标题固定为「风险后果」 |
| `note` |补充说明（灰字） |
| `details` |长文本，放进可滚动区域 |
| `countdown` |倒计时秒数 |
| `single` | `true` =只有一颗确认按钮（纯提示框，如「知道了」） |
| `wide` | `true` =卡片加宽到640px |
| `icon` |标题左侧图标字符 |
| `initialFocus` | `'ok'`让焦点落在确认按钮（默认安全按钮） |
| `onOk` / `onCancel` |回调 |
| `dismissOnBackdrop` |默认 `false`；置 `true`才允许点遮罩关闭 |

##四、`UI.showSignDialog(title, content, options)` → `Promise<{ok,id,...}|null>`

强模态签署框。内容过长自动出现「展开全文 /收起全文」，必须勾选真实 checkbox，
可选要求手写签名；**点「同意并继续」时先写审计库，写成功才算同意**。

```js
const res = await UI.showSignDialog('使用前请读完（就这几条）', text, {
 agreement: 'disclaimer', //协议标识，写库用
 version: '1.6.4', //条款版本号
 acceptText: '同意并继续',
 declineText: '暂不同意，退出',
 agreeLabel: '我已阅读并同意上述内容',
 requireSign: true, //需要手写签名（≥2字）
 auditMethod: 'audit_sign_accept'
});
if (!res) return; // null =用户不同意
console.log(res.id, res.at); //审计记录 id与落库时间
```

审计写入失败时**不会关闭弹窗**：按钮变成「重试保存并同意」，提示「签署记录没能保存，请重试」。
Esc等同「暂不同意」，不写审计。

##五、`UI.toast(msg, type, options)`

不阻断，默认2.6秒淡出，鼠标悬停暂停计时。

```js
UI.toast('已保存', 'success'); // success / error / warning / info
UI.toast('保存失败', 'error', {
 onRetry: () => save(), //出现「重试」按钮，点了立即执行
 onDetails: () => openLog(), //出现「查看详情」按钮
 undoCallback: () => restore(),//出现「撤销」按钮
 ms:4000 //停留时长
});
```

防轰炸规则：

-同内容（同类型 +同文案）**不叠加**，只原地累加计数显示 `×N`，并重置倒计时；
-同时最多3条，第4条挤掉最老的一条；
-类型别名：老的 `ok/err/warn/fail`自动映射到 `success/error/warning`。

##六、兼容层（`ui-compat.js`）

老代码**一行都不用改**，兼容层按下面的规则接管：

|老调用 |新实现 |按钮文案处理 |
| --- | --- | --- |
| `toast(msg, 'ok'/'err'/'warn')` | `UI.toast` |类型自动映射 |
| `confirmDialog(title, body, okText, danger, note)` | `UI.showConfirm` | `okText`模糊时用标题动作替换；`note`变成「风险后果」 |
| `promptDialog(title, body, def, okText)` | `UI.prompt` | `okText`为空时用「保存」 |
| `riskConfirm(...)` | `UI.showConfirm` +倒计时 |危险按钮固定红色 |
| `askRestart(featureCN)` | `UI.showConfirm` |文案保持原样（用户指定） |
|原生 `confirm()` |已被包装 |弹窗打开时直接返回 `false`，不弹原生框 |

全部替换点（行号 +改后按钮文案）见 [弹窗替换清单_V1.7.0.md](弹窗替换清单_V1.7.0.md)。

##七、国际化

组件内所有文案都走 `UI.t(key)`：先查内置 `TEXT`表（中文），再用 `window.UI_MAP[中文原文]`
翻译。`UI_MAP`由 `applyUiLang()`从后端 `get_ui_lang`拉取，也就是既有的「中文原文 →译文」机制。

**新增弹窗文案要翻译，只需在 `langs/<语言>.json`的 `ui`段加一条「中文原文:译文」**，
不用改代码。V1.7.0已给 `langs/en-US.json`补了25条组件文案。

##八、无障碍

-遮罩 `role="dialog"` + `aria-modal="true"`；
-打开时锁滚动（`html{overflow:hidden}`），关闭时还原；
-焦点锁定：Tab/Shift+Tab只在弹窗内循环；焦点被抢到背景会被拉回；点遮罩不会丢焦点；
-关闭后焦点还原到打开前的元素；
-禁用态用 `aria-disabled="true"`（不用 `disabled`，以便保留键盘可达性与点击提示）；
- `prefers-reduced-motion`与 `html[data-perf="low"]`下自动关掉动画。

##九、自验证

`_cdp_verify.py` 用真实 CDP跑32项断言（强阻断不可穿透、Toast自动消失、
Esc关闭、焦点锁定、审计失败重试等）。它是开发期临时脚本，**不随发行包分发**，
生成在**项目目录之外**的临时工作目录里（不要放回项目根，否则会被打进开源包）。
跑法：

```powershell
cd desktop\src
python -m http.server5999 --bind127.0.0.1  #另开一个窗口
python <临时工作目录>\_cdp_verify.py  #需先用 pip install playwright && playwright install chromium
```

末行会输出 `===32/32 PASS ===`。
