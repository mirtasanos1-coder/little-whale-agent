# V1.1.2 更新说明（正式版）

> 这一版没有加多少新按钮，主要是**修气人**：回得慢、问了不回、群里接不上话、界面上东西乱跳。
> 想自己改代码/打包 → `开发者指南.md`；想查每个小改动 → `更新日志.md`。

---

## 一、升级后先做三件事

1. **设置 → 聊天与回复规则 →「回复等待时间」**：按你的机器调。本地模型建议 60~90 秒；云端 20~30 秒就够。
   （以前这个值跟后台任务共用 300 秒，模型一忙你就干等五分钟。）同一张卡里还能关掉「假装打字」或把它封顶到 2 秒。
2. **模型页 →「启动顺序判定」→ 按顺序测一遍**：先 QQ 接入，再模型服务，最后出话/出图/动态。
3. **记忆页 → 左上角会话下拉**：现在能自己挑会话看了（私聊、群聊都在，绑定的会标「已绑定」）。

## 二、为什么以前"问了不回"

真凶不是你网络，是两个 bug 叠一起：

| 问题 | 以前 | 现在 |
|---|---|---|
| 去重占位 | 消息一进来就登记"我要回"，模型超时/失败也被当成"回过"，同一句 90 秒内静默吞掉 | 只有**真发出去**才登记；问句永不拦 |
| 超时太长 | 聊天和后台共用 300 秒超时，还叠四条重试链 | 聊天单独 60 秒，超时只允许换短上下文再试一次 |
| 抢模型 | 每条消息起 3 个后台线程都调模型，本地单并发，下一条排队 | 后台活儿排队，且等你**安静 8 秒**才跑；同一会话 45 秒内不重复提取 |
| 假装打字 | 2~6 秒 + 字数/12，长回复能拖 20 秒 | 0.3~1 秒 + 字数/40，封顶 2 秒 |

以上四个一起改，观感就是：**回得快了，而且不会莫名其妙不理你。**

## 三、群里为什么以前只会说"在的"

群里 @ 你、或者上线后补回消息，以前是**一句一句**丢给模型，没带任何前情 → 模型只能回"在的""在呢"。
现在补回是**整批合并**，并把最近的聊天记录一起带上，能接住上文。

## 这一轮又修了什么（截图里的红字）

- **红字 `name '_wrap' is not defined`**：不是你的配置问题，是程序内部一个包装函数被弄丢了，导致「按功能分工」「插件」整块读不出来。已补回。升级后如果还看到这条，说明你跑的是旧包。
- **点了没反应**：以前后端一卡，按钮就一直转圈。现在最多等 45 秒，会直接告诉你「哪个方法超时」，不会假装在干活。
- **打开慢半拍**：配置以前每读一个字段就读一次盘，现在文件没变就不再读，首屏设置加载快了一截。
- **情感预测**：原来只是关键词猜。现在旁边多一个「模型深判」，结合人设判情绪、潜台词和该顺着说什么；它会花一点 token，觉得没必要就别点。
- **一键启动**：以前 QQ 已经开着也会再拉一个登录窗口。现在会先看一眼，提示「先退出 QQ」，也顺手去掉了启动时闪一下的黑框。
- **界面手感**：默认不让选中文字（像桌面软件）；想复制内容就在 设置 → 外观 里打开「界面文字可选中」。同一处还有「卡片可拖大小」。
- **画图**：你说「画一张」「画个猫」，它会直接画，不用等它自己想起。


## 八、出问题怎么办

1. **设置 → 关于 →「校验文件完整性」**：先确认文件没坏。
2. **管理员页 → 诊断**：一键看版本、优先级链、记忆条数、日志尾部。
3. **日志**：程序目录下 `agent.log`，搜 `[去重]`、`[记忆导入]`、`[日记备份]`、`[画图]` 能看到各模块的动作。
4. 实在不行：`设置 → 卸载与数据保留 → 保留数据卸载`，重装后数据还在。

另外两处也顺手修了：

### 收尾又补的：急的时候真的会秒回

- **以前为什么没感觉**：程序里「对方很急 → 0.5 秒内回」这条判断写错了参数，
  拿的是"我要回多少字"去当"对方有多着急"，所以那条分支一次都没执行过。
- **现在**：普通消息还是 0.3~1 秒的假装打字（长回复最多 2 秒），
  但你着急、难受、连着追问时（「快点回我」「我好难受」「在吗在吗」），会**半秒内**回。
- **无边框模式**（设置 → 外观）：以前拖记忆分割条、拖公告会把整个窗口一起拖走，现在不会了。
- 判断有没有生效：版本号 `v1.1.2`，问一句急的话，看是不是立刻有反应。
