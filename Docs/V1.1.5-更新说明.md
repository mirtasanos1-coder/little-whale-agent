# 小鲸鱼 V1.1.5 更新说明

这一版没有新玩法，只修「用着别扭」的地方。

## 一、卡片上的雪不再压字

雪堆从卡片里面挪到了上沿外侧，厚度也收敛了。滑块拉到 100 是「厚雪压顶」，不是「糊住标题」。

## 二、雪可以分开关

设置 → 外观 → 新增两个开关：

- **卡片积雪**：卡片上沿那层雪
- **背景飘雪 / 落叶**：整页飘的那层

只想看雪不想眼晕，就关掉飘雪留雪堆。

## 三、厚度不会再被主题顶掉

以前把厚度调到 8，切个主题回来又变成默认厚度（滑块还显示 8）。现在以你调的为准。

## 四、无边框窗口重启后真的生效了

开关打开 → 选「等不及了，即刻重启」→ 新窗口没有系统标题栏、只有自绘的顶部条。
关掉开关同样会恢复原生边框。

## 五、生图不再糊里糊涂

点开生图卡，它会直接告诉你现在到底能不能出图：

- 走本地聊天模型时：「它只会写字、不能画图」，并给出两条出路
- 走云端时：缺 Key 才提示缺 Key

同时修掉一个会让整块状态显示 `TypeError` 的 bug（把文件信息当成文件路径用了）。

## 六、还没做

- 目录重构（`src/` + `Docs/`）风险太大，这一版先不动
- 程序生成的图还偏「图元拼贴」，接本地 ComfyUI 要等下一版

## 七、升级方式

覆盖 `小鲸鱼_程序包` 目录即可；配置与记忆在 `D:\qq-agent\data`（或你设的目录），不会被动。
