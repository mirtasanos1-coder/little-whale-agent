人设（personas.json）

—

JSON 结构

{
  "active": "whale",
  "personas": {
    "whale": {
      "name": "小鲸鱼",
      "persona": "你是谁…",
      "rules": "说话规则…"
    }
  }
}
  • active 决定当前生效的人设键名，必须在 personas 里存在。
  • 每个人设必须有 name 和 persona，rules 可选。
  • 用 JSON 而不是 Python 代码：改错字不会让程序起不来，报错也只会告诉你第几行第几列。
  • 保存前会做 JSON 语法 + 结构双重校验，不合格绝不写盘。
  • 保存成功会自动备份为 personas.json.bak-时间戳。

关系等级怎么算

· 陌生人（0~9）：客气、有分寸，不开玩笑
· 认识的人（10~29）：会接话，但还带着距离
· 熟人（30~59）：能闲聊几句，不冷不热
· 朋友（60~119）：说话随意，会吐槽你
· 好朋友（120~199）：会开玩笑、会追问、记得你的事
· 知己（200~349）：什么都能聊，会主动找你
· 特别的人（350+）：最亲近的一档，分寸交给伴侣模块管
· 分数只影响语气，不替代人设；关掉「告诉模型分数」就只说等级

远程控制怎么用

        
1. 在「设置 → 安全与隐私」打开管理员暗号，并设一个只有你知道的串（建议 12 位以上）。

        
2. 用绑定的 QQ 给机器人发：暗号 + 你要它做的事。

        
3. 命中后：本机会弹一个 10 秒提醒；开了「最高权限」时，模型用上面这段提示词直接回你。

        
4. 没开最高权限时：只会弹提醒 + 回一句固定话术，暗号内容不会送进模型。

        
安全提示：暗号等于本机钥匙，别发在群里、别截图外传；怀疑泄露就立刻重设。
