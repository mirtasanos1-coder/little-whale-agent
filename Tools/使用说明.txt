小鲸鱼 · 恢复官方安装（用法说明）
========================================

什么时候用
----------
· 打开就弹「文件被改过 / 被篡改」，进不去界面；
· 增量包升到一半失败，程序打不开了；
· 程序目录里被塞了乱七八糟的东西，想退回官方原版。

怎么用（三步）
--------------
1) 把「小鲸鱼_V*_绿色版.zip」和「恢复工具.zip」解压到同一个文件夹里
   （或者把绿色版 zip 放在恢复工具旁边 / 上级目录 / 桌面 / 下载目录都行）。
   来源也可以是安装包装出来的目录（那种目录的清单在 resources\ 里，脚本同样认得）。
2) 双击「恢复官方安装.bat」。
3) 按提示确认。脚本会自己找到程序目录；找不到时会让你把文件夹拖进来。

它会动什么
----------
· 只动程序文件：小鲸鱼.exe、manifest.sha256 / manifest.sig、README/说明文件、resources\ 下的
  av_server.exe、backend_server.exe、napcat_bundle.zip、static\、rpa\templates\ 等。
· 动手之前先把要覆盖的文件备份到 <程序目录>\_repair_backup\official-<时间>\。
· 写完会跑一次自检（小鲸鱼.exe --verify-self）。自检不过会**自动把备份还原回去**，
  不留半截状态。
· 会先验绿色包的签名：只有官方签发的包才会被采用。来路不明的包（哪怕文件名写着最新版）
  会在这一步被拒，不会写进你的程序目录。
· 动手之前还会核对随身带的 verify_bundle.exe：内置哈希对不上（有人把它换成了一个
  "永远说通过"的假货）就直接退出 2，一个文件都不会写。所以恢复工具要**整包**替换，
  别单独替换里面的某一个文件。

它绝不动什么
------------
· 记忆 / 日记 / 永久记忆（memory\ 或 memory.db）
· 人设与头像（personas\、persona_faces\）
· 设置（config.json）、自定义音色（resources\av_module\voices\）
· 日志与备份（agent.log、_backup\、_repair_backup\）
· 防护章的锁（guard.seal）与审计（guard_audit.log）

注意：guard.seal 属于你的数据，本工具不会换锁。如果之前在设置里关过注入防护，
恢复后请去「设置 → 安全」确认那几个开关是开着的。

关进程的规矩
------------
只关「这个程序目录里」正在跑的小鲸鱼 / backend_server / av_server。
另一份安装（比如测试版放在别的盘）不会被碰。

退出码（出问题时截图给我们就行）
--------------------------------
0 = 成功
2 = 找不到官方包 / 包没通过签名校验 / 工具不完整（缺 verify_bundle.exe）/ verify_bundle.exe 被换过
3 = 程序关不掉（请在任务管理器里结束这个目录下的进程再重跑）
9 = 写入或自检失败，已自动回滚

小提示
------
· 绿色版 zip 和恢复工具请用「官方的」；恢复工具会验签，验不过就不动手。
· 恢复完成后程序目录里会多一个 _repair_backup\，确认没问题后可以自己删掉腾空间。
